# Map Mode

<!-- standards:invocation -->

```json
{
  "schemaVersion": 1,
  "kind": "mode",
  "group": "conversation-mode",
  "id": "MAP",
  "label": "Map",
  "description": "Sketch how the parts of an area connect, as a text map.",
  "selection": "user"
}
```

Use the shared Navigator procedure and boundaries. Draw a compact text map of
the user-named area in the conversation: its main modules or files, the entry
points, and the calls, data, or events that connect them. Label each box and
arrow with the exact path it comes from.

Keep the map to what the evidence shows. Mark guessed or unverified links as
such, and follow the map with a short reading order. Do not create diagram
files or add tools to render the map.
