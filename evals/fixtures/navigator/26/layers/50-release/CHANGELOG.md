# Changelog

## 0.3.0 (2026-09-20)

- Added the `largest` option to `format_duration` and `--largest` to the
  command line.

## 0.2.0 (2026-08-02)

- Spaces inside a duration are now ignored.
- Units must appear in `d`, `h`, `m`, `s` order and at most once each.

## 0.1.0 (2026-06-15)

- First release: `parse`, `format_duration`, and the `durfmt` command.
