# Catalog Search

## Goal

Let kiosk users find books by typing part of a title or an author's name,
without scrolling the whole catalog.

## Constraints

- The catalog stays in memory; no new dependencies.

## Non-goals

- Fuzzy matching, spelling correction, or search by subject.
- Paging through results beyond the first page.

## Work

### 1. Search the catalog

**Intent:** Kiosk users can narrow the catalog to the books they want.

**Done when:**

- `AC-001`: Searching for a word in a book's title returns that book.
- `AC-002`: Matching ignores letter case and surrounding spaces in the query.
- `AC-003`: Searching for part of an author's name returns that author's books.
- `AC-004`: A search returns at most 20 results, ordered by title.

**Depends on:** None
