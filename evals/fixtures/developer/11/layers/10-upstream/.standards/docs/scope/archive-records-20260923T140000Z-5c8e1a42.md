# Record Archiving

## Goal

Users keep finished records for reference, but those records clutter the
default record list. Let users archive a record so it leaves the default list
without being deleted, while it stays readable on request.

## Constraints

- Existing record API calls and their responses keep working for current
  callers.
- Records stay in the existing in-memory store; no new persistence.

## Non-goals

- Unarchiving (restoring) archived records.
- Archiving records automatically by age or content.

## Work

### 1. Archive a record

**Intent:** Give users a way to set a record aside without losing it.

**Done when:**

- `AC-001`: A user can archive an existing record through the records API; the record is kept, and reading it shows it as archived. Archiving a record that does not exist reports not found.

**Depends on:** None

### 2. Keep archived records out of the default list

**Intent:** Remove archived records from the everyday list while keeping them
reachable.

**Done when:**

- `AC-002`: The default record list omits archived records. A caller can explicitly ask the list to include them, and the existing title search applies either way.

**Depends on:** 1
