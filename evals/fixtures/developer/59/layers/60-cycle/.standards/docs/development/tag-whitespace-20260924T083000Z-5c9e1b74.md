### DEV-001 — Collapse internal whitespace in normalizeTag

`Status`: `PENDING` `Depends On`: `NONE` `Acceptance`: `EXPEDITED_REQUEST`

**Goal**

Make tag normalization turn every internal run of whitespace into one hyphen
while keeping the existing trim and lowercase behavior.

**Affected Area**

`src/tags.js` (`normalizeTag`). `parseTags` and `TagStore` in `src/store.js`
already route every tag through `normalizeTag`, so they need no change.

**Expected Outcome**

`normalizeTag("  Field   Notes ")` returns `"field-notes"`; tabs and other
whitespace count as whitespace; single-word tags are unchanged, and lookups
through `TagStore.itemsTagged` match the new form.

Run `npm test` (`node --test test/tags.test.js`) from the project root after the
change, plus a quick `node -e` call of `normalizeTag` on a multi-space name. Not
run yet; the plan awaits approval.
