`Status`: `PENDING` `Depends On`: `NONE` `Acceptance`: `EXPEDITED_REQUEST`

**Goal**

Run the project's ruff lint rules in CI so lint failures are reported on pushes
to `main` and on pull requests, separately from test failures.

**Affected Area**

in `pyproject.toml`, and ruff is declared with an exact version in the `dev`

the same events. It sets up Python 3.12, installs the ruff version declared in
the `dev` extra, and runs `ruff check .` from the repository root. The `test`
job keeps its current behavior.
