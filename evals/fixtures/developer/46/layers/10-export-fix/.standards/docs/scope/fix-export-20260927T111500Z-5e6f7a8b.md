# CSV Export Quoting

## Goal

Make exported CSV safe to open in spreadsheet tools when item titles contain
commas, double quotes, or line breaks, without changing exports of plain values.

## Non-goals

- New export columns or formats.
- Changes to how tags are joined within a field.

## Work

### 1. Quote special fields

**Intent:** Titles such as `Pens, assorted` currently split into extra columns
when the export is opened.

**Done when:**

- `AC-001`: An exported field containing a comma, double quote, or line break is enclosed in double quotes, with each embedded double quote doubled.
- `AC-002`: Fields without those characters are exported unchanged, so exports of plain values stay byte-identical.

**Depends on:** None
