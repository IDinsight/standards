### DEV-001 — Quote special characters in exported fields

`Status`: `DONE` `Depends On`: `NONE`
`Acceptance`: `AC-001, AC-002`

**Goal**

Apply RFC 4180 quoting to row values in `toCsv` as the design specifies.

**Affected Area**

`src/export.js`

**Expected Outcome**

Row values containing a comma, double quote, carriage return, or line feed are
wrapped in double quotes with embedded quotes doubled; other values and the
header row are unchanged.

**Self-Check**

- `node --test test/catalog.test.js test/export.test.js` in the project root,
  on `${COMMIT:Initial catalog module with CSV export}` plus the working-tree
  change to `src/export.js`: exit 0, 4 tests passed.
- An inline `node -e` call in the project root exporting an item titled
  `Pens, "fine"` printed the row `3,"Pens, ""fine""",ink`.

Limitation: the existing suite has no scenario with quoted fields; formal
coverage is left to Tester.
