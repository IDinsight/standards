# Technical Design

## Context

`toCsv` in `src/export.js` joins `id`, `title`, and the `;`-joined tags with
commas and applies no quoting.

## Decision

Add a private `field(value)` helper in `src/export.js` that applies RFC 4180
quoting only when the value contains a comma, a double quote, a carriage return,
or a line feed, and run every row value through it. The fixed header row stays
unquoted and the line separator stays a single line feed.

## Acceptance Coverage

- `AC-001`: `field()` wraps values containing a comma, double quote, carriage return, or line feed in double quotes and doubles embedded quotes.
- `AC-002`: `field()` returns all other values unchanged; the header row and line separator are unchanged.

## Build Plan

1. Add `field()` and apply it to each row value in `toCsv`.
