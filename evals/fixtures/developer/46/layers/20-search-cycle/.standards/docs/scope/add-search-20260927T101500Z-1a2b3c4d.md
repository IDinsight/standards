# Catalog Search

## Goal

Let callers find catalog items by a word in their title or by tag without
knowing the item id.

## Non-goals

- Fuzzy matching or ranking by relevance.
- Changes to CSV export.

## Work

### 1. Search catalog items

**Intent:** Callers currently have to list every item and filter by hand.

**Done when:**

- `AC-001`: Searching for a word returns every item whose title contains that word, ignoring case.
- `AC-002`: Searching for a tag returns every item carrying that tag, ignoring case and surrounding spaces.
- `AC-003`: A query that matches nothing, or an empty or blank query, returns an empty list.

**Depends on:** None
