# Improve User Search

## Goal

Make directory search find the people users are looking for without requiring
exact capitalization, and let them search by email address as well as name.
Show the most likely matches, those whose name starts with the query, first.

## Constraints

- The command-line output format (`Name <email>`, one line per user) stays the
  same.
- A blank or whitespace-only query continues to return no results.

## Non-goals

- Fuzzy or typo-tolerant matching.
- Paging or limiting the number of results.
- Searching fields other than name and email.

## Work

### 1. Case-insensitive name and email matching

**Intent:** Users should not have to remember how a name or address is
capitalized, and should be able to find someone from part of their email.

**Done when:**

- `AC-001`: A query matches a user whose name contains it, regardless of
  letter case.
- `AC-002`: A query matches a user whose email address contains it, regardless
  of letter case.

**Depends on:** None

### 2. Name-prefix matches first

**Intent:** With broader matching, the most likely intended people should be at
the top of the results.

**Done when:**

- `AC-003`: Users whose name starts with the query, ignoring case, are listed
  before all other matches; within each group the directory's existing order
  is kept.

**Depends on:** 1
