# admin-records

Admin user records for the back office: creation, validated updates, and the
HTML detail table shown on the admin record page.

- `src/adminRecords.js` — record shape, editable fields, and update validation.
- `src/store.js` — in-memory store used by the admin pages.
- `src/render.js` — renders a record as a labelled HTML table.

Run the tests with `npm test` (Node 22, no dependencies).
