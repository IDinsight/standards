# Technical Design

## Context

`stock` parses the inventory CSV in `src/inventory.js` and prints tables with
`formatTable` in `src/format.js`; `src/cli.js` dispatches commands.

## Decision

Add a pure selection function in a new `src/report.js` and a `low` command in
`src/cli.js`. Selection and ordering live in `report.js`; the CLI only loads,
selects, and prints. How the table is rendered is a local choice as long as the
layout matches `list`.

## Acceptance Coverage

- `AC-001`: `lowStock(items)` in `src/report.js` keeps items with strict
  `qty < reorderAt`.
- `AC-002`: `low` command in `src/cli.js`: `loadInventory` then `lowStock`, then
  table output in the `list` layout; `lowStock` orders by ascending `qty`, ties
  by `sku`.
- `AC-003`: the `low` command prints the fixed message to stdout when
  `lowStock` returns an empty array; the exit code stays 0.

## Interfaces and Contracts

- `lowStock(items)` returns a new array and does not mutate its input.
- CLI: `stock low <file>`; a missing file argument is a usage error, as for
  `list`.

## Technical Acceptance Criteria

- `AC-001`: an item with `qty` equal to `reorderAt` is not returned.
- `AC-002`: column order `sku, name, qty, reorderAt`, same layout as `list`.
- `AC-003`: message on stdout, exit code 0.

## Build Plan

1. Selection function in `src/report.js`.
2. `low` command and its output in `src/cli.js`.
