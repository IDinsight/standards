# Low-Stock Report

## Goal

Warehouse staff need to see which items must be reordered without scanning the
whole inventory list. Add a report of the items whose quantity has fallen below
their reorder point.

## Constraints

- Uses the existing inventory CSV format; no new input columns.
- Output is plain text in the same table style as `stock list`.

## Non-goals

- Placing orders or computing order quantities.
- Changing the `list` command.

## Work

### 1. Low-stock report

**Intent:** Let staff get the reorder list directly from the inventory file.

**Done when:**

- `AC-001`: The report includes exactly the items whose `qty` is below their
  `reorderAt`; items at or above their reorder point are excluded.
- `AC-002`: `stock low <inventory.csv>` prints the low-stock items as a table
  with `sku`, `name`, `qty`, and `reorderAt` columns, lowest `qty` first.
- `AC-003`: When no item is below its reorder point, `stock low <inventory.csv>`
  prints `No items below reorder point.` and exits with status 0.

**Depends on:** None
