`Status`: `DONE` `Depends On`: `NONE` `Acceptance`: `AC-001`

Provide `lowStock(items)` in a new `src/report.js` that returns the items whose

`Status`: `PENDING` `Depends On`: `DEV-001` `Acceptance`: `AC-002, AC-003`

**Goal**

`lowStock`, and prints the result through the existing `formatTable` with

**Affected Area**

`src/cli.js` (usage message and command dispatch).

`No items below reorder point.` and exits 0; the usage message lists both
