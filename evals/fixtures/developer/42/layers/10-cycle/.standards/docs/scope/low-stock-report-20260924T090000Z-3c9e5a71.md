# Low-Stock Report

## Goal

Warehouse staff read the stock report to decide what to reorder. Today it lists
quantities only, so staff compare each line against reorder levels kept
elsewhere. The report should show which items have reached their reorder level
and how many there are.

## Constraints

- The inventory stays a plain comma-separated file.
- Existing three-column inventory files must keep loading.

## Non-goals

- Creating purchase orders or any automatic reordering.
- A project-wide default reorder level.

## Work

### 1. Low-stock flagging

**Intent:** Let staff see at a glance which items need reordering.

**Done when:**

- `AC-001`: An item can carry an optional reorder threshold in the inventory
  file; an item whose quantity is at or below its threshold is marked as low
  stock on its line in the stock report.
- `AC-002`: An item without a reorder threshold is never marked as low stock,
  and existing three-column inventory files load without changes.
- `AC-003`: The report's summary line states how many items are low stock.

**Depends on:** None
