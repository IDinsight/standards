# Technical Design

## Context

The CLI keeps calculations in `inventory/stock.py` and printing in
`inventory/cli.py`. The low-stock report follows the same split.

## Decision

Add a pure selection function to `stock.py` and a `low-stock` subcommand to
`cli.py` that formats its result.

## Acceptance Coverage

- `AC-001`: `low_stock(items)` in `stock.py` selects items with
  `quantity <= reorder_level`; the `low-stock` subcommand prints one line per
  selected item.
- `AC-002`: `low_stock` returns the selection sorted by `(quantity, sku)`.
- `AC-003`: the `low-stock` subcommand prints the fixed message when the
  selection is empty and returns 0.

## Interfaces and Contracts

- `low_stock(items: list[Item]) -> list[Item]`: does not mutate its input.
- Output line format: `<sku>\t<name>\t<quantity>\t<reorder_level>`.
- Empty result: the single line `No items at or below reorder level.`; exit
  status 0 in every non-error case.

## Technical Acceptance Criteria

- `AC-001`: an item whose quantity equals its reorder level is included.
- `AC-002`: ties on quantity are broken by SKU in string order.

## Build Plan

1. Selection and ordering in `stock.py`.
2. Subcommand and output formatting in `cli.py`.
