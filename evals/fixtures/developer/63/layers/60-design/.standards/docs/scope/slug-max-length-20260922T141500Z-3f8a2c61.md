# Slug Maximum Length

## Goal

Callers that store slugs in fixed-width columns or short URLs need slugs with a
bounded length, without words cut in half where that can be avoided.

## Constraints

- Existing calls that do not ask for a maximum length must keep producing
  identical slugs.
- No new runtime dependencies.

## Non-goals

- Changing how characters are normalized or which characters are kept.
- A configurable separator or a truncation marker such as an ellipsis.

## Work

### 1. Bounded slug length

**Intent:** Let a caller cap slug length while keeping slugs readable.

**Done when:**

- `AC-001`: When a caller asks for a maximum length, the slug is no longer than
  that length and ends at the last whole word that fits; if the first word alone
  is longer than the limit, it is cut at the limit.
- `AC-002`: Calls without a maximum length return the same slugs as before.
- `AC-003`: A maximum length that is not a positive whole number is rejected
  with an error instead of producing a slug.

**Depends on:** None
