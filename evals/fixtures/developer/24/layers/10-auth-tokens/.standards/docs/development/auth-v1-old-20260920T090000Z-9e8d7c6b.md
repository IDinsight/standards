## Build Steps

### DEV-001 — Signed token helper

`Status`: `DONE` `Depends On`: `NONE` `Acceptance`: `EXPEDITED_REQUEST`

**Goal**

Provide signing and verification of session token payloads with an HMAC
secret.

**Affected Area**

New module `src/tokens.js`.

**Expected Outcome**

`signToken(payload, secret)` returns `<base64url body>.<base64url mac>`;
`verifyToken(token, secret)` returns the payload for a valid token and `null`
for a malformed or tampered one.

**Self-Check**

`node --test test/sessions.test.js test/login.test.js` in the project root on
the working tree with `src/tokens.js` added: exit 0, 4 passes. Round trip
checked with `node -e` signing and verifying `{ userId: 1 }`; a token with an
altered signature returned `null`.

`Status`: `PENDING` `Depends On`: `DEV-001` `Acceptance`: `EXPEDITED_REQUEST`
