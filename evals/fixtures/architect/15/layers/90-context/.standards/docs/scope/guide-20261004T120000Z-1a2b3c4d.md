# Report Command Guide

## Goal

Give people who keep a ledger with tally one accurate guide to the
`tally report` command, and make it easy to find from the README.

## Constraints

- Documentation-only cycle: edit `docs/reports.md` and the README usage
  section; leave `tally/`, `tests/`, and `examples/` unchanged.
- Describe `tally report` as the current code behaves.

## Non-goals

- Changing report output, options, or error handling.
- Documenting how to edit ledger files.

## Work

### 1. Report guide

**Intent:** Readers can run a report and read its output without opening the
source.

**Done when:**

- `AC-001`: `docs/reports.md` explains how to run `tally report` on a ledger
  file, including the `--account` filter and the message and exit status for a
  missing ledger file.
- `AC-004`: `docs/reports.md` shows the report output as `tally report` writes
  it for `examples/sample.csv`, including the delimiter, the header row, the
  column order, and how totals are formatted.

**Depends on:** None

### 2. README pointer

**Intent:** Readers who start at the README find the guide.

**Done when:**

- `AC-003`: The README usage section links to `docs/reports.md`.

**Depends on:** Work item 1

## Retired Acceptance Identifiers

- `AC-002`: Retired; it assumed tab-separated output that `tally report` does
  not write. Replaced by AC-004.
