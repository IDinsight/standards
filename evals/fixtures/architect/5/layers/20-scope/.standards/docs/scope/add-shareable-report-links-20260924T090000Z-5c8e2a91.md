# Shareable Report Links

## Goal

Users currently share a report by copying its rows into a message or sending a
screenshot, which goes stale as soon as the data changes. Users want a link to
a report that they can send, so the recipient can open the report directly.

## Non-goals

- Exporting reports to CSV or PDF.
- Scheduled delivery of reports by email.
- Editing a report through a link.

## Work

### 1. Report links

**Intent:** Let a user hand someone a link to a report instead of a copy of its
contents.

**Done when:**

- `AC-001`: Users can create shareable report links.

**Depends on:** None
