# Technical Design

## Context

Documentation cycle for the existing csvsum tool. The behavior to document is
established in `.standards/CONTEXT.md` and in `csvsum/cli.py` and
`csvsum/summary.py`; no implementation change is planned. No project references
apply.

## Decision

Document the command-line contract below as it exists at the start of the
cycle. The guide treats `python3 -m csvsum` run from the repository root as the
only supported invocation, because the project has no packaging metadata.
Examples use `examples/orders.csv` so readers can reproduce them.

## Acceptance Coverage

- `AC-001`: Arguments and column selection under Interfaces and Contracts;
  evidence `csvsum/cli.py` (`build_parser`, `main`) and `csvsum/summary.py`
  (`summarize`).
- `AC-002`: Cell handling and output under Interfaces and Contracts; evidence
  `format_line` in `csvsum/cli.py` and `_number` in `csvsum/summary.py`.
- `AC-003`: Errors under Interfaces and Contracts; evidence the exception
  handling in `csvsum/cli.py` and argparse defaults.
- `AC-004`: No architectural impact — the README link is Documenter-owned prose
  with no technical contract.

## Interfaces and Contracts

- Arguments: positional `path`, opened as UTF-8 with `newline=""`;
  `--column NAME`, repeatable (`action="append"`); `--delimiter CHAR`, default
  `,`, passed to `csv.DictReader`.
- Column selection: without `--column`, all header fields in header order; with
  it, the given names in the given order. A name not in the header raises
  `KeyError` before any row is read.
- Cell handling: each cell is stripped and parsed with `float`; blank and
  unparsable cells are skipped and do not count.
- Output: one line per selected column,
  `NAME: count=N min=MIN max=MAX mean=MEAN`, with min and max in Python `g`
  format and the mean to two decimal places; a column with no numeric cells
  prints `NAME: no numeric values`.
- Errors: a missing file prints `csvsum: no such file: PATH` to standard error
  and exits 2; an unknown column prints `csvsum: unknown column: NAME` to
  standard error and exits 2; argparse argument errors exit 2; success exits 0.

## Technical Acceptance Criteria

- `AC-001`, `AC-002`: Examples in the guide reproduce exactly with
  `examples/orders.csv` at the documented revision.
- `AC-003`: Messages are quoted verbatim from `csvsum/cli.py`.
