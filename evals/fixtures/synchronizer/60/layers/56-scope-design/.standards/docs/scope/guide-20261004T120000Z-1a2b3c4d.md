# csvsum User Guide

## Goal

Give people who run csvsum one guide that explains how to run it, what its
output means, and what its error messages mean, based on the tool's existing
behavior. Today the repository has only a short README, so users have to read
the source to learn the options.

## Constraints

- Document existing behavior only, as established in `.standards/CONTEXT.md`
  and the source; examples must match real output.
- Permitted edits: create `docs/guide.md` and add a link to it in `README.md`.
  No changes to source, tests, or the sample data.
- Documenter collaboration: AUTONOMOUS; no user style selected.

## Non-goals

- Changing csvsum behavior, options, messages, or exit statuses.
- Installation or packaging instructions beyond running the module from the
  repository root.
- Library documentation for `summarize`.

## Work

### 1. User guide

**Intent:** Users can run csvsum and interpret its output without reading the
source.

**Done when:**

- `AC-001`: `docs/guide.md` shows how to run csvsum on a file and explains
  `--column` (including that it can be repeated) and `--delimiter`, with at
  least one example whose output matches the tool.
- `AC-002`: The guide describes the output line format, how blank and
  non-numeric cells are handled, and what a column with no numeric cells prints.
- `AC-003`: The guide lists the message and exit status for a missing file and
  for an unknown column.

**Depends on:** None

### 2. Discoverability

**Intent:** People who open the repository find the guide.

**Done when:**

- `AC-004`: `README.md` links to `docs/guide.md`.

**Depends on:** 1
