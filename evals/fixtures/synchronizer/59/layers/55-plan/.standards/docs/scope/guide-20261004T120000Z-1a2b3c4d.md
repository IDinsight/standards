# Rates CLI User Guide

## Goal

Give people who quote parcels with the `rates` CLI one guide that explains how
to get a quote, which zones exist, how weight is billed, and what the errors
mean, describing the tool as it behaves today.

## Constraints

- Document existing behavior only. The guide lives at `docs/guide.md`; the
  README may link to it.
- No changes to source, tests, or package configuration.

## Non-goals

- Changing rates, rounding, or CLI behavior.
- A reference for importing `src/rates.js` as a library.

## Work

### 1. User guide

**Intent:** Users currently have to read the source to learn the default zone,
how weight is billed, and what each error means.

**Done when:**

- `AC-001`: The guide explains how to run a quote, including the default zone
  and the output format.
- `AC-002`: The guide lists every zone with its rates and states how billable
  weight is rounded, matching `src/rates.js`.
- `AC-003`: The guide describes each error case with its message and exit
  code.

**Depends on:** None
