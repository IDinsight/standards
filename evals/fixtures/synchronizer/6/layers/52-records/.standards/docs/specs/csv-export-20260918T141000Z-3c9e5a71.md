# Technical Design

## Context

Records live in the in-memory store in `src/store.js`; there is no export path.

## Decision

Add a pure function `toCsv(rows, columns)` in a new `src/export.js`. It does
not depend on the store, so callers pass `store.list()`.

## Acceptance Coverage

- `AC-001`: `toCsv` in `src/export.js`; quoting rules under Interfaces and
  Contracts.
- `AC-002`: No architectural impact — Documenter owns the README section.

## Interfaces and Contracts

- `toCsv(rows, columns?)` returns a string. `columns` defaults to the keys of
  the first row; with no columns it returns `''`. Lines end in CRLF, including
  the last. `null` and `undefined` become empty cells.

## Technical Acceptance Criteria

- `AC-001`: A field is wrapped in double quotes exactly when it contains `,`,
  `"`, CR, or LF; embedded `"` is written as `""`. Header names use the same
  rule.
