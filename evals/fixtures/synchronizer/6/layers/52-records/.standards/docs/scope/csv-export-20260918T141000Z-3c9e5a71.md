# CSV Export

## Goal

Let operators download stored records as CSV text that spreadsheet tools open
correctly.

## Constraints

- No new runtime dependencies.

## Non-goals

- Importing records from CSV.

## Work

### 1. CSV serialization

**Intent:** Operators need the stored records in a spreadsheet without broken
rows when values contain punctuation.

**Done when:**

- `AC-001`: Exported CSV has a header row followed by one line per record, and
  fields containing commas, double quotes, or line breaks are quoted per RFC
  4180 with embedded quotes doubled.

**Depends on:** None

### 2. Usage documentation

**Intent:** Operators and maintainers can find how to produce an export.

**Done when:**

- `AC-002`: The README explains how to produce a CSV export and how columns are
  chosen.

**Depends on:** 1
