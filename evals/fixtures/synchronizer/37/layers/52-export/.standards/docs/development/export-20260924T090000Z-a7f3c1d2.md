### DEV-001 — CSV output for the filtered records list

`Status`: `DONE` `Depends On`: `NONE` `Acceptance`: `EXPEDITED_REQUEST`

**Goal**

Return the records list, with the listing filters applied, as CSV.

**Affected Area**

New `src/export.ts` (`csvCell`, `toCsv`) with unit tests in
`test/export.test.ts`; a `format=csv` query parameter on `GET /records` in
`src/routes/records.ts`.

**Expected Outcome**

`GET /records?format=csv` returns the records `GET /records` lists for the
same filters as `text/csv; charset=utf-8`: header
`id,title,owner,status,createdAt`, one CRLF-terminated row per record, fields
with a comma, double quote, CR, or LF quoted per RFC 4180. Without
`format=csv` the listing stays JSON.
