# Export Format Option

## Goal

The export CLI chooses JSON output with a boolean `--json` flag. More output
formats are expected, and one flag per format does not scale and allows
contradictory combinations. Replace the flag with a single `--format` option
so callers name the format they want, and keep the usage guide accurate.

## Constraints

- CSV stays the default output, and its content does not change.
- `--status`, `--owner`, and `--out` keep their current behavior.
- `--json` is removed outright; this internal tool needs no deprecation
  period.

## Non-goals

- Output formats other than CSV and JSON.
- Changes to the bundled records or the CSV quoting rules.

## Work

### 1. Format option

**Intent:** Callers select the output format by name.

**Done when:**

- `AC-001`: `--format csv` and `--format json` produce CSV and JSON output of the matching records; without `--format` the output is CSV, identical to the output before this change.

**Depends on:** None

### 2. Removed flag and invalid formats

**Intent:** Callers that still pass the old flag, or a format that does not
exist, find out immediately instead of getting unexpected output.

**Done when:**

- `AC-002`: Passing `--json`, or a `--format` value other than `csv` or `json`, exits with status 2, prints an error on standard error, and writes no output to standard output or to an `--out` file.

**Depends on:** 1

### 3. Usage guide

**Intent:** Readers of the usage guide learn the new option without reading
the code.

**Done when:**

- `AC-003`: The usage guide `docs/usage.md` documents `--format` and its values and no longer presents `--json` as an option.

**Depends on:** 1, 2
