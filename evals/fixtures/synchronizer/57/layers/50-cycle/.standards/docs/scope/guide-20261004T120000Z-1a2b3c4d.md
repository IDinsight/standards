# tally usage guide

## Goal

Bring `docs/usage.md` up to date so that someone with a checkout can run
`tally`'s `summary` and `check` commands correctly without reading the source.
The current guide mentions only the default summary.

## Constraints

- Documentation only. Edits are limited to `docs/usage.md`; code, tests,
  `data/expenses.csv`, and `README.md` stay unchanged.
- Commands and example output must match the current behavior of `tally` on
  `data/expenses.csv`.

## Non-goals

- Documenting every command-line option.
- Changing or extending CLI behavior.

## Work

### 1. Usage guide

**Intent:** Give users an accurate, runnable description of the input format
and the two commands.

**Done when:**

- `AC-001`: The guide states the required CSV columns and the expected date and
  amount formats.
- `AC-002`: The guide shows how to print totals by category and by month, with
  example output that matches running those commands on `data/expenses.csv`.
- `AC-003`: The guide shows how to check that a file can be read with `check`,
  and gives the exit status for success and for an unreadable or invalid file.

**Depends on:** None
