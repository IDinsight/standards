# Admin CSV Export

## Goal

Administrators need to download every record as a CSV file for offline
reporting. The download must not expose record data to anyone else.

## Constraints

- Use the project's existing CSV quoting rules in `src/csv.js`.
- Roles come from the authenticated account already attached to each request.

## Non-goals

- Filtering, pagination, or column selection in the export.
- Changes to the JSON listing.
- User-facing documentation changes.

## Work

### 1. Admin CSV download

**Intent:** Give administrators a complete, spreadsheet-ready copy of the
records.

**Done when:**

- `AC-001`: An administrator who requests the export receives every record as
  CSV, with a header row and one line per record, quoted by the existing CSV
  rules.

**Depends on:** None

### 2. Restricted access

**Intent:** Keep record data limited to administrators.

**Done when:**

- `AC-002`: Any export request that does not come from an administrator
  receives status 403 and no record data.

**Depends on:** 1
