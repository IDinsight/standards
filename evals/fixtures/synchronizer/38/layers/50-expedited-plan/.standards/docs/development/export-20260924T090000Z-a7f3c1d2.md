## Build Steps

### DEV-001 — CSV serialization with RFC 4180 quoting

`Status`: `PENDING` `Depends On`: `NONE` `Acceptance`: `EXPEDITED_REQUEST`

**Goal**

Turn a list of records into CSV text that spreadsheet programs read
correctly, including titles with commas, quotes, or line breaks.

**Affected Area**

New module `src/export.ts` (`csvCell`, `toCsv`), with unit tests in
`test/export.test.ts` as the self-check harness.

**Expected Outcome**

`toCsv(records)` returns the header row `id,title,owner,status,createdAt`
followed by one row per record in the given order, every row ending with CRLF.
`csvCell` encloses a value that contains a comma, double quote, CR, or LF in
double quotes and doubles each double quote inside it; other values are
written unchanged.

**Self-Check**

`pnpm --filter export test` in the project root.

### DEV-002 — Export file naming and writing

`Status`: `PENDING` `Depends On`: `DEV-001` `Acceptance`: `EXPEDITED_REQUEST`

**Goal**

Write an export to a configurable folder under a timestamped file name.

**Affected Area**

`src/export.ts` (`exportFileName`, `writeExport`); `.gitignore`.

**Expected Outcome**

`writeExport(dir, records, now)` creates `dir` when missing, writes
`records-<YYYYMMDDTHHMMSSZ>.csv` (UTC time of `now`) containing
`toCsv(records)`, and returns the file name, path, and CSV text. `exports/` is
ignored by git.

**Self-Check**

`pnpm --filter export test:integration` once DEV-003 provides the route it
drives; compare the written file with the expected CSV.

### DEV-003 — Administrator-only export route

`Status`: `PENDING` `Depends On`: `DEV-002` `Acceptance`: `EXPEDITED_REQUEST`

**Goal**

Expose the export through the app to administrators only.

**Affected Area**

New `src/routes/export.ts` (`registerExportRoutes`); `src/app.ts`
(`exportDir` and `now` options, route registration); `package.json`
(`test:integration` script) and `test/integration/export-flow.test.ts` as the
end-to-end self-check harness.

**Expected Outcome**

`POST /records/export` calls `requireAdmin` first, then applies `parseFilter`
to the query, lists the matching records, writes the export, and returns 201
with `content-type: text/csv; charset=utf-8`, a `content-disposition`
attachment header naming the file, and the CSV as the body. A request without
a user or from a non-admin role gets the router's 401 or 403 JSON error before
any folder or file is created. `GET /records` is unchanged.

**Self-Check**

`pnpm --filter export test` and `pnpm --filter export test:integration`;
inspect the handler's statement order.
