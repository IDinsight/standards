# CLI Usage Guide Examples

## Goal

People learn to use `records-export` from the usage guide `docs/cli.md`, but
its examples use options the command does not have (`--input`, `--out`, `-d`)
and a space-separated column list, so the examples fail or misbehave when
copied. The guide must show invocations that work with the command as it is
today.

## Constraints

- The command's established behavior is the reference; this cycle does not
  change it.
- The guide stays in `docs/cli.md`.

## Non-goals

- New options, aliases for the options the old examples used, or any other
  change to the command.
- Documentation other than the CLI usage guide.

## Work

### 1. Correct invocation examples

**Intent:** Someone copying an example from the guide gets the result the
guide describes.

**Done when:**

- `AC-001`: Every invocation example in `docs/cli.md` runs as written against the current `records-export` command from the repository root with `examples/records.json`, and the output, files, messages, and exit status the guide states for its examples and options match what the command does.

**Depends on:** None
