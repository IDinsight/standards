# Convert Command Guide

## Goal

Give people who use the CLI a usage guide for the existing `rowtool convert`
command, so they can run it and predict its output without reading the source.

## Constraints

- Documentation-only cycle: no changes to source, tests, examples, or
  configuration.
- The guide describes the current behavior of `convert` as implemented.
- The new guide lives under `docs/guides/`.

## Non-goals

- Documenting `rowtool validate`.
- Changing `convert` behavior, including adding quoted-field support.
- Reworking `README.md`.

## Work

### 1. Convert usage guide

**Intent:** One page a CLI user can follow to run `convert` and understand the
JSON it produces.

**Done when:**

- `AC-001`: `docs/guides/convert.md` shows the `rowtool convert` invocation and
  explains the input argument and each supported option (`--delimiter`,
  `--out`), including the delimiter default, matching current behavior.
- `AC-002`: The guide states where the JSON is written by default and where it
  is written when `--out` is given.
- `AC-003`: The guide explains how header names become keys and how short and
  long rows are handled, with an example whose output matches what the command
  produces.

**Depends on:** None

## Assumptions

- Readers run the CLI from a checkout, as the README describes.
