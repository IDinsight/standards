# Explicit Export Columns

## Goal

Callers of the CSV export need to choose which columns appear and in what
order, instead of always getting the keys of the first row.

## Constraints

- No new dependencies.
- Existing callers that pass no column list keep their current output.

## Non-goals

- Renaming columns or changing header labels.
- Changes to the README or other user-facing documentation.
- Rejecting unknown column names.

## Work

### 1. Column selection

**Intent:** Let a caller fix the exported columns and their order.

**Done when:**

- `AC-001`: When a column list is given, the CSV header and every row contain
  exactly those columns, in the given order.
- `AC-002`: A requested column that is missing from a row is written as an empty
  field.

**Depends on:** None

### 2. Existing behavior

**Intent:** Keep current callers working unchanged.

**Done when:**

- `AC-003`: Without a column list, the export output is unchanged: columns come
  from the first row's keys and empty input still yields an empty string.

**Depends on:** None
