# Import Command User Guide

## Goal

People who receive bank-export CSV files need to run `ledger import` without
reading the source. Document the existing command accurately in a user guide and
make the guide easy to find from the README.

## Constraints

- Documentation-only cycle: edits are limited to a new `docs/import-guide.md`
  and prose in `README.md`.
- The guide describes current behavior as implemented in `src/` and `bin/`; it
  does not propose changes.

## Non-goals

- Changing the import command, its tests, or the sample fixture.
- Adding quoted-field support or other input formats.
- Documenting `parseCsv` or `runImport` for use as a library.

## Work

### 1. Import guide

**Intent:** Give command-line users one place to learn how to run an import and
read its results.

**Done when:**

- `AC-001`: The guide explains how to run `ledger import`, including the `--out`
  and `--dry-run` options, consistent with current behavior.
- `AC-002`: The guide explains the accepted CSV input: required and optional
  columns, date and amount formats, and known input limitations.
- `AC-003`: The guide explains the output (summary line and JSON fields) and the
  exit codes and error messages of failed imports.

**Depends on:** None

### 2. Discoverability

**Intent:** Readers who open the repository find the guide without searching.

**Done when:**

- `AC-004`: The README links to the import guide.

**Depends on:** 1
