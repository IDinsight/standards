# ledgerline CLI User Guide

## Goal

Give people who run `ledgerline` one guide that explains the statement file
format, how to check a statement and read a monthly summary, and what each exit
code means, describing the tool exactly as it behaves today.

## Constraints

- Documentation-only cycle: describe the existing behavior of `ledgerline`
  0.4.1. No changes to source, tests, configuration, or example data.
- Permitted edit: a new `docs/guide.md`.
- Examples use `examples/statement.csv` and must reproduce the tool's actual
  output.

## Non-goals

- Changing CLI behavior, adding quoted-field support, or adding CLI tests.
- Reference documentation for the `src/` modules.
- Rewriting `README.md`.

## Work

### 1. User guide

**Intent:** Users currently have only a two-command README and no description
of the file format or exit codes.

**Done when:**

- `AC-001`: `docs/guide.md` explains the statement file format and the `import`
  command, with an example whose output matches the current tool.
- `AC-002`: `docs/guide.md` explains the `summary` command and its `--month`
  option, with an example whose output matches the current tool.
- `AC-003`: `docs/guide.md` lists every exit code the CLI returns, with the
  condition for each, matching `bin/ledgerline.js`.

**Depends on:** None
