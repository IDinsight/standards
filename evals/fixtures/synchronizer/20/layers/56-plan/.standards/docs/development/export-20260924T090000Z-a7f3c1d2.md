## Build Steps

### DEV-001 — Accounts feed source

`Status`: `PENDING` `Depends On`: `NONE` `Acceptance`: `AC-001, AC-002`

**Goal**

Read accounts from a JSON Lines feed as the design defines.

**Affected Area**

`partner_export/sources.py` (`JsonlFeedSource`, `FeedError`), with unit tests
in `tests/test_feed_source.py` as the self-check harness.

**Expected Outcome**

`JsonlFeedSource(path).accounts()` yields `Account` values with the design's
field mapping, skips blank lines, ignores extra fields, and raises `FeedError`
with the 1-based line for an unreadable line.

**Self-Check**

`python3 -m pytest -q` in the project root.

### DEV-002 — Switch the export to the feed and retire the dump

`Status`: `PENDING` `Depends On`: `DEV-001` `Acceptance`: `AC-001`

**Goal**

Make the feed the export's only source.

**Affected Area**

`partner_export/settings.py`; remove `TsvDumpSource`,
`tests/test_tsv_source.py`, and `data/legacy/accounts.tsv`; add
`data/feed/accounts.jsonl` with the same accounts as the sample dump.

**Expected Outcome**

`make_source()` returns `JsonlFeedSource(FEED_PATH)`; nothing reads the dump;
the partner file built from the sample feed equals the one built from the
sample dump.

**Self-Check**

`python3 -m pytest -q`; run the command line on the sample feed and compare
with the file the dump produced.

### DEV-003 — Fail without a partial file

`Status`: `PENDING` `Depends On`: `DEV-002` `Acceptance`: `AC-002`

**Goal**

Stop the export cleanly when the feed cannot be read.

**Affected Area**

`partner_export/export.py` (`write_export`), `partner_export/__main__.py`,
`tests/test_export.py`, `tests/test_cli.py`.

**Expected Outcome**

`write_export` reads every account before opening the output file; the
command line prints `error: <message>` and returns 1 on `FeedError` or
`OSError`, leaving no output file.

**Self-Check**

`python3 -m pytest -q`.
