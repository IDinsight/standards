# Technical Design

## Context

Documentation cycle. The scope asks for a configuration guide for the existing
rotation helper and a README link. Behavior comes from `src/rotate.js` as
recorded in `.standards/CONTEXT.md`; no implementation change is planned.

## Decision

Document the public contract of `src/rotate.js` as it exists. The guide is a
new file, `docs/guide.md`; the README gets one link. No changes to code, tests,
or configuration are proposed.

## Acceptance Coverage

- `AC-001`: Options contract below: `DEFAULTS` in `src/rotate.js` (`maxBytes`
  1048576, `keep` 5) merged with caller options, the size comparison in
  `shouldRotate`, and the `keep` validation in `rotate`.
- `AC-002`: Backup naming contract below, from the rename sequence in
  `rotate`.
- `AC-003`: No architectural impact — the README link is Documenter-owned
  prose.

## Interfaces and Contracts

- `shouldRotate(file, options)`: false when the file is missing; true when its
  size is at least `maxBytes`. Does not validate `keep`.
- `rotate(file, options)`: throws `RangeError` when `keep` is not a positive
  integer; returns false when the file is missing; otherwise deletes
  `file.keep` if present, renames `file.n` to `file.n+1` from `n = keep - 1`
  down to 1, renames `file` to `file.1`, and returns true. It does not create a
  new log file.
- `rotateIfNeeded(file, options)`: calls `rotate` only when `shouldRotate`
  returns true; otherwise returns false.

## Technical Acceptance Criteria

- `AC-001`: Stated defaults, option meanings, and validation match `DEFAULTS`,
  the `>=` comparison, and the `keep` check in `src/rotate.js`.
- `AC-002`: Stated naming, newest/oldest order, and deletion order match
  `rotate`.
