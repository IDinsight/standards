# Log Rotation Guide

## Goal

Developers embedding `rotalog` currently have to read `src/rotate.js` to learn
what the options do and which backup files appear on disk. Give them a guide
that describes the existing behavior accurately, and make it easy to find from
the README.

## Constraints

- Documentation only: edits are limited to a new `docs/guide.md` and the
  README. No changes to `src/`, `test/`, or `package.json`.
- The guide describes behavior as implemented today.

## Non-goals

- Changing rotation behavior or adding options such as compression or
  time-based rotation.
- API reference for internal helpers.

## Work

### 1. Configuration guide

**Intent:** Developers can configure rotation without reading the source.

**Done when:**

- `AC-001`: The guide explains `maxBytes` and `keep`, including their defaults
  and accepted values, consistent with `src/rotate.js`.
- `AC-002`: The guide describes the backup naming sequence, which backup is
  newest and oldest, and what happens to the oldest backup on rotation.

**Depends on:** None

### 2. Discoverability

**Intent:** Readers of the README can find the guide.

**Done when:**

- `AC-003`: The README links to the guide.

**Depends on:** Work item 1
