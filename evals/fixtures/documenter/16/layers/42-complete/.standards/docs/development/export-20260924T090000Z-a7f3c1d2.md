### DEV-002 — Filtered, quoted export_csv

`Status`: `DONE` `Depends On`: `DEV-001` `Acceptance`: `AC-001`

**Goal**

Make `RecordStore.export_csv` follow the design's contract.

**Affected Area**

`records/store.py` (`RecordStore.export_csv`); `tests/test_export.py`.

**Expected Outcome**

`export_csv(path, status=None, owner=None, columns=DEFAULT_COLUMNS)` filters
through `list`, builds rows with `csv_rows` before opening the file, writes
them with `csv.writer` to a file opened with `newline=""`, and returns the
number of records written. `export_csv(path)` still writes every record with
all five columns.

**Self-Check**

- `python3 -m pytest` in the project root at commit
  `${COMMIT:Filter exports, select columns, and quote CSV fields}`: exit 0;
  15 passed, 0 failed. The export tests compare the written bytes, including
  CRLF line endings and quoting of commas, double quotes, and line breaks.
- The pre-cycle export test in `tests/test_store.py` passes unchanged, so
  `export_csv(path)` keeps its meaning.

**Implementation Notes**

`csv_rows` returns a list rather than a generator so that an unknown column
is reported before the file is opened.
