### DEV-001 — Column validation and CSV rows

`Status`: `PENDING` `Depends On`: `NONE` `Acceptance`: `AC-001`

**Goal**

Build the rows of an export, header first, for the selected columns.

**Affected Area**

New module `records/export.py` (`DEFAULT_COLUMNS`, `csv_rows`); tests in
`tests/test_export.py` as the self-check harness.

**Expected Outcome**

`csv_rows(records, columns)` returns the column names followed by one list of
values per record, in the given order. An empty column list or a name outside
`DEFAULT_COLUMNS` raises `ValueError` before any row is built.

**Self-Check**

`python3 -m pytest` in the project root.

### DEV-002 — Filtered, quoted export_csv

`Status`: `PENDING` `Depends On`: `DEV-001` `Acceptance`: `AC-001`

**Goal**

Make `RecordStore.export_csv` follow the design's contract.

**Affected Area**

`records/store.py` (`RecordStore.export_csv`); `tests/test_export.py`.

**Expected Outcome**

`export_csv(path, status=None, owner=None, columns=DEFAULT_COLUMNS)` filters
through `list`, builds rows with `csv_rows` before opening the file, writes
them with `csv.writer` to a file opened with `newline=""`, and returns the
number of records written. `export_csv(path)` still writes every record with
all five columns.

**Self-Check**

`python3 -m pytest` in the project root; byte comparison of the written files
in the export tests.
