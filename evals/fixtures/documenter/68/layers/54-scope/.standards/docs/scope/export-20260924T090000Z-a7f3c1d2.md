# CSV Export of Records

## Goal

Administrators of the records admin tool need to take the list they are
looking at, after filtering it by status, owner, or title text, into a
spreadsheet. The service should produce that list as a CSV file that
spreadsheet programs read correctly even when titles contain commas, quotes,
or line breaks. Export files hold record data, so only administrators may
create them. The admin tool's developers integrate the export through the
service's API, so they need a guide to the export endpoint that matches how
it actually works.

## Constraints

- An export applies the same filters, with the same validation, as listing
  records (`GET /records`).
- Access is decided by the service, not by the admin tool's user interface.
- Listing records keeps its current behavior.
- The export endpoint gets its own API guide at `docs/api/export.md`, written
  for the admin tool's developers.

## Non-goals

- Formats other than CSV, choosing or reordering columns, and scheduled or
  emailed exports.
- Listing or removing previously created export files.
- Changes to the admin tool's front end.

## Work

### 1. Administrator CSV export

**Intent:** Let administrators save exactly the records they filtered as a
CSV file, and keep record data in export files limited to administrators.

**Done when:**

- `AC-001`: Administrators can export the currently filtered records as CSV, with any field containing a comma, double quote, or newline quoted per RFC 4180 and embedded double quotes doubled.
- `AC-002`: An export request from a user who is not an administrator, or from no signed-in user, is denied by server-side authorization before any export file is written.

**Depends on:** None

### 2. API guide for the export

**Intent:** The admin tool's developers can call the export correctly without
reading the service code.

**Done when:**

- `AC-003`: The API guide `docs/api/export.md` accurately describes the export endpoint: who may call it, the filters it accepts, the response it returns and the file it writes, and its error responses.

**Depends on:** 1

## Assumptions

- Export files are kept by the service; how the admin tool offers them for
  download is outside this repository.
