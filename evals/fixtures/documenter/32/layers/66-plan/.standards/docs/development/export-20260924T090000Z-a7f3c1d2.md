## Build Steps

### DEV-001 — CSV serialization with RFC 4180 quoting

`Status`: `PENDING` `Depends On`: `NONE` `Acceptance`: `AC-001`

**Goal**

Turn a list of records into the CSV text the design defines.

**Affected Area**

New module `recordsvc/export.py` (`csv_cell`, `to_csv`), with unit tests in
`tests/test_export.py` as the self-check harness.

**Expected Outcome**

`to_csv(records)` returns the header row `id,title,owner,status,created_at`
followed by one row per record in the given order, every row ending with
CRLF. `csv_cell` encloses a value that contains a comma, double quote, CR, or
LF in double quotes and doubles each double quote inside it; other values are
written unchanged.

**Self-Check**

`python3 -m pytest tests/test_export.py` in the project root.

### DEV-002 — Export file naming and writing

`Status`: `PENDING` `Depends On`: `DEV-001` `Acceptance`: `AC-001`

**Goal**

Write an export to the configured folder under the design's file name.

**Affected Area**

`recordsvc/export.py` (`export_file_name`, `write_export`); `.gitignore`.

**Expected Outcome**

`write_export(directory, records, now)` creates `directory` when missing,
writes `records-<YYYYMMDDTHHMMSSZ>.csv` (UTC time of `now`) containing
`to_csv(records)` with its CRLF line ends kept, and returns
`(file_name, path, csv)`. `exports/` is ignored by git.

**Self-Check**

`python3 -m pytest tests/test_export_route.py` once DEV-003 provides the
route it drives; compare the written file with the expected CSV.

### DEV-003 — Administrator-only export route

`Status`: `PENDING` `Depends On`: `DEV-002` `Acceptance`: `AC-001`

**Goal**

Expose the export through the app to administrators only.

**Affected Area**

`recordsvc/api.py` (`export_records`, `App` options `export_dir` and `now`,
route registration); `tests/test_export_route.py` as the end-to-end self-check
harness; `tools/apidoc.json` (list `recordsvc.export`) and the regenerated
`docs/api/reference.md`.

**Expected Outcome**

`POST /records/export` calls `require_admin` first, then applies
`parse_filter` to the query, lists the matching records, writes the export,
and returns 201 with `content-type: text/csv; charset=utf-8`, a
`content-disposition` attachment header naming the file, and the CSV as the
body. A request without a user or from a non-admin role gets the 401 or 403
JSON error before any folder or file is created. `GET /records` is unchanged.

**Self-Check**

`python3 -m pytest` and `python3 tools/apidoc.py --check`; inspect the
handler's statement order.
