# Tony

My preferences for guides I write or review.

- Address the reader as "you".
- Start each new section with a one-sentence summary in bold.
- List query parameters in a table with the columns Parameter, Values, Notes.
- Call out side effects (files written, data changed) in a paragraph that
  starts with "Heads up:".
- End each endpoint section with a worked example: the request line, then the
  full response.
