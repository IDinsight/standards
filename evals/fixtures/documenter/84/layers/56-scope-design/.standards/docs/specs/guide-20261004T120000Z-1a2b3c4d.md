# Technical Design

## Context

Documentation cycle for `docs/operator-guide.md`. Existing behavior is defined
by `reportkit/config.py`, `reportkit/export.py`, and `reportkit/prune.py` (see
`.standards/CONTEXT.md`). No implementation change is planned; this design
records the existing contracts the guide must describe.

## Decision

Document the library's public functions as they are: `load_config`,
`format_rows`, `export_rows`, `prune`, and `cutoff_for`. Defaults and accepted
values come from the module constants in `reportkit/config.py`. Examples use
doctest syntax so the established `python3 -m doctest` command checks them.

## Acceptance Coverage

- `AC-001`: `load_config(values)` in `reportkit/config.py`: keys
  `retention_days` (`DEFAULT_RETENTION_DAYS`, whole number, at least 1),
  `output_format` (`DEFAULT_FORMAT`, one of `FORMATS`), and `output_dir`
  (`DEFAULT_OUTPUT_DIR`, any path). Raises `ValueError` for a retention below 1
  or an unknown format.
- `AC-002`: `format_rows(rows, output_format)` in `reportkit/export.py`: CSV
  through `csv.DictWriter` with the header taken from the first row's keys and
  newline line endings, an empty string for no rows; JSON Lines with one
  sorted-key object per line. `export_rows(rows, config, name)` writes
  `<output_dir>/<name>.<output_format>`, creating the directory, and returns the
  path.
- `AC-003`: `prune(directory, retention_days, now=None)` in
  `reportkit/prune.py` deletes regular files whose modification time is before
  `cutoff_for(now, retention_days)` (`now - retention_days * 86400`), leaves
  directories and newer files, and returns the removed names sorted.
- `AC-004`: No architectural impact — link resolution is checked by the
  existing `scripts/check_links.py`.
- `AC-005`: No architectural impact — governed by the "Corrections after
  review" rule in `docs/CONTRIBUTING.md`; satisfied in the documentation phase.
