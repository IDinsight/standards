# reportkit

Small helpers for exporting report rows to CSV or JSON Lines and pruning old
export files.

- Operator guide: [docs/operator-guide.md](docs/operator-guide.md)
- Documentation conventions: [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md)

## Commands

- `python3 -m pytest` runs the unit tests.
- `python3 -m doctest docs/operator-guide.md` runs the guide's examples.
- `python3 scripts/check_links.py docs/operator-guide.md` checks relative links
  in a guide.
