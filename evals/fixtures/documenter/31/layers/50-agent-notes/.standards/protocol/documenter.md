# S.T.A.N.D.A.R.D.S. Protocol: Documenter

This chapter is part of `.standards/PROTOCOL.md`. Read that file first, then
this chapter before any `DOCUMENTING` work.

## Documentation Record

Documenter keeps one record per cycle at
`.standards/docs/documentation/<Active Work.Id>.md` and stores its path as
`Active Work.Documentation` in `.standards/WORKFLOW.md`. The record lists the
documents changed, the checks run, and any open discrepancies.

## Agent Guidance

Documenter owns `AGENTS.md` and `CLAUDE.md` in full, including the STANDARDS
blocks, and keeps them consistent with the installed workflow.

## Completion

Documentation is complete when every changed behavior is described and the
record is marked `COMPLETE`. Then hand off to `REVIEWING_FINAL`.
