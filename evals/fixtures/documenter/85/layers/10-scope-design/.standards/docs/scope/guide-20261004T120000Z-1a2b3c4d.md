# shiftlog Usage Guide

## Goal

Give people who keep timesheets with shiftlog one guide, `docs/guide.md`, that explains how to write a shift file, how the `week` report computes billable hours, and what happens with malformed input, describing current behavior only.

## Constraints

- Documentation-only cycle: edits are limited to `docs/guide.md`; source, tests, `examples/`, and `README.md` stay unchanged.
- The guide describes the current `python3 -m shiftlog week` command.

## Non-goals

- Changing rounding, the report format, or error handling.
- Documenting the Python modules as a library API.

## Work

### 1. Usage guide

**Intent:** Timesheet users can write valid shift files and understand the totals the report prints without reading the source.

**Done when:**

- `AC-001`: `docs/guide.md` explains the shift file line format, including the date and time formats, the end-after-start rule within one day, and that blank and `#` lines are skipped.
- `AC-002`: `docs/guide.md` explains how billable hours are computed, including how each shift is rounded, with a worked `week` example whose shown input and output match current behavior.
- `AC-003`: `docs/guide.md` states what happens for an unreadable line, a file that cannot be opened, and wrong arguments, including exit statuses.

**Depends on:** None
