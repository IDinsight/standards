# Technical Design

## Context

Documentation cycle for `docs/guide.md`. Existing behavior lives in `shiftlog/parse.py`, `shiftlog/report.py`, and `shiftlog/__main__.py`; see `.standards/CONTEXT.md`. The contracts below are recorded from the source at `${COMMIT:Initial shiftlog package}`. No project references apply.

## Decision

Document the command as it behaves today. No implementation changes; the guide is the only edited file.

## Acceptance Coverage

- `AC-001`: Shift line contract in `parse_line` and `parse_lines` (below).
- `AC-002`: Rounding and report contract in `billable_minutes`, `daily_hours`, and `format_week` (below).
- `AC-003`: Error and exit-status contract in `main` in `shiftlog/__main__.py` (below).

## Interfaces and Contracts

- Shift line: `YYYY-MM-DD HH:MM-HH:MM`, parsed with `date.fromisoformat` and `time.fromisoformat`. The end time must be later than the start time, so a shift cannot cross midnight. Blank lines and lines whose first non-space character is `#` are skipped. Unreadable lines raise `ShiftError` with a `line N:` prefix.
- Rounding: `billable_minutes` rounds each shift's length up to the next multiple of 15 minutes. `daily_hours` sums the rounded minutes per day, in date order, and converts them to hours.
- Output: `format_week` prints one `YYYY-MM-DD  H.HH` line per day and a `Total` line with the sum, both with two decimals.
- Command: `python3 -m shiftlog week FILE`. Exit 0 with the report on standard output; exit 1 with `shiftlog: <message>` on standard error for an unreadable line or a file that cannot be opened; exit 2 with the usage line for wrong arguments.
