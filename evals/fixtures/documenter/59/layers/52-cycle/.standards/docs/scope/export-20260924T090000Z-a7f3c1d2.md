# Invoice JSON Export

## Goal

Finance staff and partner integrations need the invoices for a period in a
machine-readable form without paging through `GET /invoices` and filtering
client-side. Add a JSON export for a date range and a reference guide for it.

## Constraints

- The export must represent invoices exactly as the existing invoice API does.
- The existing CSV export keeps its current behavior.

## Non-goals

- Changes to the CSV export or its columns.
- Authentication or access control.
- Filtering by anything other than issue date.

## Work

### 1. JSON export endpoint

**Intent:** Let a client fetch the invoices issued in a period in one request.

**Done when:**

- `AC-001`: A client can request the invoices issued within a date range as JSON from a dedicated export endpoint.
- `AC-002`: Exported invoices use the same field names, timestamp format, and amount representation as `GET /invoices`.
- `AC-003`: A request with a missing, malformed, or reversed date range is rejected with status 400 and an error message, and returns no invoices.

**Depends on:** None

### 2. Export API guide

**Intent:** Give integrators a reference for the export without reading the
code.

**Done when:**

- `AC-004`: A new guide at `docs/api/export.md` documents the export endpoint, its parameters and range rules, the response shape, and its error responses.

**Depends on:** Work item 1.
