### DEV-001 — CSV serialization with RFC 4180 quoting

`Status`: `DONE` `Depends On`: `NONE` `Acceptance`: `AC-001`

**Goal**

Turn a list of records into the CSV text the design defines.

**Affected Area**

New module `src/csv.js` (`csvCell`, `toCsv`), with unit tests in
`test/export.test.js` as the self-check harness.

**Expected Outcome**

`toCsv(records)` returns the header row followed by one CRLF-terminated row
per record; `csvCell` quotes values containing a comma, double quote, CR, or
LF and doubles embedded double quotes.

**Self-Check**

- `npm test` in the project root at commit
  `${COMMIT:Add CSV export of filtered records}` (clean tree, Node 22):
  exit 0; 18 tests passed, 0 failed, including the five serialization tests.

### DEV-002 — Export file naming and writing

`Status`: `DONE` `Depends On`: `DEV-001` `Acceptance`: `AC-001`

**Goal**

**Affected Area**

**Expected Outcome**

### DEV-003 — Administrator-only export route

`Status`: `DONE` `Depends On`: `DEV-002` `Acceptance`: `AC-001`

**Goal**

Expose the export through the app to administrators only.

**Affected Area**

New `src/routes/export.js`; `src/app.js` (`exportDir` and `now` options);
`package.json` test script; route tests in `test/export.test.js`.

**Expected Outcome**

`POST /records/export` calls `requireAdmin` first, then lists the records
matching `parseFilter(request.query)`, writes the export, and returns 201 with
the CSV headers and body. Requests without a user or from a non-admin role get
401 or 403 before any folder or file is created. `GET /records` is unchanged.

**Self-Check**

- Same `npm test` run: the denied-export test (no user, viewer, editor) passes
  and the export folder is never created.
- Inspection of `src/routes/export.js` at that commit:
  `requireAdmin(request.user)` is the handler's first statement.
