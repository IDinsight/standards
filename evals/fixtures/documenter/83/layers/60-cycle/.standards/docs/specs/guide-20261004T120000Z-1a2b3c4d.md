# Technical Design

## Context

Documentation cycle for the configuration guide (`docs/configuration.md`). No
implementation changes are planned; this design records the existing contracts
the guide must describe and the established build that publishes it. Behavior
sources: `src/config.js`, `src/ledger.js`, `src/cli.js`, with
`test/config.test.js` and `test/ledger.test.js` as supporting evidence. Project
context: `.standards/CONTEXT.md`.

## Decision

Treat `DEFAULTS` and `loadConfig` in `src/config.js` as the source of truth for
the option set, defaults, and allowed values, and `src/ledger.js` for how each
option affects a run. Keep the guide's existing structure: an introduction with
one JSON example, one `##` section per option, and `:::note` blocks for
behavior notes.

## Acceptance Coverage

- `AC-001`: Option set and defaults from `DEFAULTS`; allowed values from the
  validation in `loadConfig`; run effects from `parseLedger` and
  `formatAmount`. See Interfaces and Contracts.
- `AC-002`: `loadConfig(options)` is the acceptance contract for examples;
  `src/cli.js` passes the parsed `ledgerline.json` object to it unchanged.
- `AC-003`: `npm run docs:build` runs `node scripts/build-docs.mjs`, which loads
  the plugins listed in `docs.config.json` in order
  (`./scripts/docs-plugins/anchors.mjs` for heading ids, then
  `@inkpress/callouts` for `:::note` blocks), renders each `docs/*.md` page, and
  writes `site/<page>.html`.

## Interfaces and Contracts

- `currency`: default `USD`; a string of three uppercase letters; printed after
  each total.
- `dateFormat`: default `YYYY-MM-DD`; one of `YYYY-MM-DD`, `DD/MM/YYYY`,
  `MM/DD/YYYY`; a row whose date does not match stops the run with
  `Invalid date "<value>" at line <n>`.
- `roundTo`: default `2`; a whole number from 0 to 4; decimal places in printed
  totals.
- `skipEmptyRows`: default `true`; boolean; when `false`, a blank line stops the
  run with `Empty row at line <n>`.
- `delimiter`: default `,`; one of comma, semicolon, or tab (`"\t"` in JSON);
  separates the date, account, and amount fields.
- Any other key is rejected with `Unknown option: <key>`; the CLI prints
  `ledgerline: <message>` and exits 1.
- `ledgerline.json` is read from the current directory; `--config <path>` reads
  another file. A missing default file means all defaults apply; a missing
  `--config` file is an error.

## Technical Acceptance Criteria

- `AC-001`: Each of the five options above appears in `docs/configuration.md`
  with its default and allowed values as listed.
- `AC-002`: Each JSON example in the guide, parsed and passed to `loadConfig`,
  returns without throwing.
- `AC-003`: `npm run docs:build` exits 0 and `site/configuration.html` contains
  the rendered callouts for the page's `:::note` blocks.

## Risks and Follow-up

- Ledger rows are split on the delimiter without quoting, so an account name
  cannot contain the delimiter; describe this as current behavior if the guide
  mentions it.
