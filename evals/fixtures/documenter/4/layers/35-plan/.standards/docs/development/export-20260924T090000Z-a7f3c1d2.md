## Build Steps

### DEV-001 — CSV serialization

`Status`: `PENDING` `Depends On`: `NONE` `Acceptance`: `AC-001`

**Goal**

Turn a list of records into the CSV text the design defines.

**Affected Area**

New module `recordbook/export.py` (`to_csv`); unit tests in
`tests/test_export.py` as the self-check harness.

**Expected Outcome**

`to_csv(records)` returns the header row and one CRLF-terminated row per
record, with RFC 4180 quoting from the `csv` module.

**Self-Check**

`python3 -m pytest` in the project root.

### DEV-002 — Output path and file writing

`Status`: `PENDING` `Depends On`: `DEV-001` `Acceptance`: `AC-001`

**Goal**

Choose the output file and write it without replacing existing files by
default.

**Affected Area**

`recordbook/export.py` (`default_export_path`, `write_export`); `.gitignore`.

**Expected Outcome**

`default_export_path(dir, now)` returns `records-<UTC stamp>.csv` in `dir`;
`write_export(records, path, force)` creates parent folders, refuses an
existing file with `FileExistsError` unless `force`, and returns the path.

**Self-Check**

`python3 -m pytest` in the project root.

### DEV-003 — export subcommand

`Status`: `PENDING` `Depends On`: `DEV-002` `Acceptance`: `AC-001`

**Goal**

Expose the export on the command line.

**Affected Area**

`recordbook/cli.py` (`export` subparser, `cmd_export`).

**Expected Outcome**

`python3 -m recordbook export` accepts the list filters, `-o/--output`,
`--export-dir`, and `--force`, prints the written path, reports the record
count on stderr, and exits 1 with a message when the file exists.

**Self-Check**

`python3 -m pytest`; manual runs of the command in a temporary folder.
