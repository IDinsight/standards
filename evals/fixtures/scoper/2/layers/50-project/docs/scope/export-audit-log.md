# Audit log export

Compliance asked for a way to take the audit log out of the console for the
quarterly reviews. Administrators should be able to download what they see in
the audit log view as a CSV file they can open in a spreadsheet.

The export should respect whatever filters are applied in the view (actor,
action, date range) and should be available only to the people who can already
see the audit log.

Out of scope for now: scheduled exports, emailing reports.
