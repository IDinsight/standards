# Notification Preferences

## Goal

Let users choose which kinds of notifications they receive, so that the
notifications they do get stay relevant.

## Work

### 1. Per-type preferences

**Intent:** Reduce noise for users who only care about some notification types.

**Done when:**

- `AC-001`: A user can turn each notification type on or off.
- `AC-002`: A user receives no notifications of a type they turned off.

**Depends on:** None
