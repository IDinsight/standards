# Reading list idea

I keep losing track of the books people recommend to me. I want something I
can run in a terminal to:

- jot down a book (title and author) when someone mentions it;
- see what is still on the list and what I have finished;
- mark a book finished when I am done with it.

It only needs to work for me on my own machine. Sharing lists, syncing, and
ratings can wait.
