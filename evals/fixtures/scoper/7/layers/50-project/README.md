# notekeep

notekeep is a command-line tool for keeping personal notes, organized per
account. An account holds its notebooks, notes, tags, and settings. Several
people can share one installation, each with their own account.

The project is at the planning stage; no code has been written yet.

## Documentation

- `docs/operations.md` — operations guide for people who install and run
  notekeep for themselves or a small team.
