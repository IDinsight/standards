# ledger-export

`ledger-export` turns the finance team's JSON transaction dumps into CSV or JSON extracts, filtered by date range and account.

The navigation at the top of each page lists every page in this site.

## Where things live

- `src/cli.js`: the command-line entry point.
- `src/export.js`: record selection and output formats.
- `examples/transactions.json`: a small sample input.

For contributor setup, tests, and building this site, see [Development](development.md).
