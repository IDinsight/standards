# Account Balance Report Guide

## Goal

Support staff need one guide that tells them how to produce account balance
reports with the existing `acctreport` command, so they no longer ask
engineering each time. The guide describes current behavior only.

## Constraints

- Documentation only. Permitted edits: create `docs/reporting-guide.md` and add
  one link to it from `README.md`.
- Commands and example output in the guide must match what the current
  `acctreport` command does with the sample ledger `data/ledger.csv`.

## Non-goals

- Any change to `acctreport` behavior, options, output, tests, or sample data.
- Documentation of the report module's internals for developers.
- Troubleshooting malformed ledger files.

## Work

### 1. Producing a report

**Intent:** Let a support staff member produce a balance report without help.

**Done when:**

- `AC-001`: The guide explains how to produce a CSV balance report from a
  ledger file, names each output column and what it contains, and includes an
  example whose output matches the command's actual output for
  `data/ledger.csv`.

**Depends on:** None.

### 2. Audience

**Intent:** Readers can tell at once whether the guide is for them and what they
need before starting.

**Done when:**

- `AC-002`: The guide opens by naming its audience, support staff who pull
  account balance reports from a terminal, and states what they need before
  running any command.

**Depends on:** None.

## Retired Acceptance Identifiers

- `AC-003`: Retired before architecture began because the user dropped the
  troubleshooting section for malformed ledger files; see Non-goals.
