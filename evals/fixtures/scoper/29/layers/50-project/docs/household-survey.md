# Household survey (v2)

Paper questionnaire the field team completes at each household visit.
Enumerators type the completed forms into a shared spreadsheet at the end of
the day.

1. Household code (three letters and five digits, from the assignment sheet)
2. Visit date
3. Enumerator ID
4. Consent given (yes / no). If no, stop the interview here.
5. Number of people living in the household (0 to 30)
6. Main drinking water source: piped, borehole, protected well, unprotected
   well, surface water, or other
7. Main source of household income (free text)
8. Enumerator notes (optional, up to 500 characters)
