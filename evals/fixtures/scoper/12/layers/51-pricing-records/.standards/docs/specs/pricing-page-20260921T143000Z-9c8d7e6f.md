# Technical Design

## Context

The repository has no implementation yet. The pricing page is the first public
page and must be servable without a backend.

## Decision

Build the pricing page as a static HTML page with a stylesheet. Plan data lives
in a JSON file that is read when the page is built, so prices change without
editing markup.

## Acceptance Coverage

- `AC-001`: `plans.json` holds plan names and monthly prices; the page renders one card per plan.
- `AC-002`: Each plan card's call to action links to `/trial`.

## Build Plan

1. Add `plans.json` and the page template.
2. Render the plan cards and their trial links.
