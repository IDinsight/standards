# account-portal

Customer account portal. It renders the billing summary that signed-in
customers see.

- `src/billing/summary.js` renders the billing summary.
- `src/billing/copy.js` holds the customer-facing strings.

Run the tests with `npm test`.

## Product scope

`docs/product/scope.md` is the canonical product scope for the portal.
Changes to customer-facing behavior or copy, including billing copy, are
scoped there before they are built.
