# Operator Configuration Guide

## Goal

Operators who run the nightly export cleanup job need one place in README.md
that explains every configuration option the library accepts, its default, and
how long archives are kept, so they can configure the job without reading the
source. The retention period is the one announced to customers.

## Constraints

- Documentation only: edits are limited to prose in README.md. Source, tests,
  fixtures, and configuration are not changed.
- Stated defaults and examples describe the library's existing behavior.

## Non-goals

- Changing any default, validation rule, or pruning behavior.
- Documenting the cleanup job's scheduler, which lives in another repository.

## Work

### 1. Configuration reference

**Intent:** Give operators an accurate reference for `loadConfig` options and
the default retention period.

**Done when:**

- `AC-001`: README.md has a Configuration section that lists every option
  accepted by `loadConfig` with its type, default, and validation rule.
- `AC-002`: README.md states the default archive retention period in days,
  matching the 30-day retention announced to customers.

**Depends on:** None

## Assumptions

- The announced 30-day retention matches the library's current default.
