# Technical Design

## Context

Per `.standards/CONTEXT.md`, handlers are synchronous functions on `Router`,
`parseFilter` and `RecordStore.list` implement the listing filters,
`requireAdmin` exists unused, and the service runs as a single worker: one
Node process that serves every request.

## Decision

Add `POST /records/export`: `requireAdmin` first, then `parseFilter`,
`RecordStore.list`, CSV serialization, a file in the export folder, and the
same CSV as the response. Repeats are recognized with an in-memory table of
recent exports owned by the app instance. Since one worker serves every
request, that table sees every repeat, and no shared store or lock is needed.

## Acceptance Coverage

- `AC-001`: the route, CSV format, and file location below.
- `AC-002`: `requireAdmin` as the handler's first step; nothing is written
  before it returns.
- `AC-003`: the recent-exports table (repeat suppression below).

## Interfaces and Contracts

- `POST /records/export` with the `GET /records` query filters. No user: 401;
  editor or viewer: 403; invalid `status`: 400. No file in these cases.
- New export: 201, `content-type: text/csv; charset=utf-8`,
  `content-disposition: attachment; filename="<name>"`, body equal to the file.
- CSV: header `id,title,owner,status,createdAt`, rows in id order, CRLF after
  every row; fields with a comma, double quote, CR, or LF are quoted with inner
  quotes doubled.
- File: `<exportDir>/records-<YYYYMMDDTHHMMSSZ>.csv` from `now()` in UTC, with
  `-2`, `-3`, ... when the name is taken; `exportDir` defaults to `exports`
  and is created when missing.
- Repeat suppression (`src/recentExports.ts`): the same user id and parsed
  filter less than `repeatWindowMs` (60000) after an earlier export returns
  200 with the earlier file name and CSV and writes nothing. Expired entries
  are dropped when a new export is recorded.

## Technical Acceptance Criteria

- `AC-001`: exported rows equal `GET /records` for the same query; quoting as
  above; body equals the written file.
- `AC-002`: 401 or 403 with no export folder or file created.
- `AC-003`: a repeat within 60 seconds returns 200 with the first file and
  writes nothing; at or after 60 seconds, or with other filters, a new file is
  written.

## Risks and Follow-up

- The table is lost on process restart, so a repeat right after a restart
  writes a new file. Accepted: restarts are rare.

## Alternatives

- A shared store for recent exports: rejected; with a single worker an
  in-memory table covers every request.
