# tally User Guide

## Goal

Give people who keep a CSV time log one guide to running `tally`: how to start
it, what the file must contain, and what each option does, matching the tool's
current behavior.

## Constraints

- Documentation-only cycle: edits are limited to a new `docs/guide.md`. No
  changes to source, tests, package metadata, or `README.md`.
- Describe version 0.3.0 as it exists; examples must reproduce with the current
  code.

## Non-goals

- Changing or extending tally's behavior, including support for quoted CSV
  fields.
- Installation or publishing instructions beyond running from a checkout.
- API documentation for the modules in `src/`.

## Work

### 1. Running tally

**Intent:** A new user can run the tool and understand its output.

**Done when:**

- `AC-001`: `docs/guide.md` explains how to run tally on a CSV file and
  describes the summary output, with an example whose output matches what the
  current code prints for the example input.

**Depends on:** None.

### 2. Input file

**Intent:** Users can prepare a file that tally accepts.

**Done when:**

- `AC-002`: The guide documents the required columns, the accepted date and
  hours values, how extra columns are treated, and what happens when a value is
  invalid.

**Depends on:** None.

### 3. Options

**Intent:** Users can narrow and group the totals.

**Done when:**

- `AC-003`: The guide documents each command-line option (`--by`, `--from`,
  `--to`) with its accepted values and its behavior when not given.

**Depends on:** Work item 1.
