### DEV-001 — Store and edit the internal note

`Status`: `DONE` `Depends On`: `NONE` `Acceptance`: `EXPEDITED_REQUEST`

**Goal**

Tickets carry an optional `internalNote` that staff can set or clear through
the existing update path.

**Affected Area**

`src/tickets.js` (`create`, `update`, field normalization) and `EDIT_ACCESS` in
`src/visibility.js`.

**Expected Outcome**

New tickets have `internalNote: null`. An update with `internalNote` stores the
trimmed text, or `null` for blank input, and roles outside the `STAFF` tier get
the existing "may not change" error.

### DEV-002 — Return the note through the existing visibility rules

`Status`: `DONE` `Depends On`: `DEV-001` `Acceptance`: `EXPEDITED_REQUEST`

**Goal**

**Affected Area**
