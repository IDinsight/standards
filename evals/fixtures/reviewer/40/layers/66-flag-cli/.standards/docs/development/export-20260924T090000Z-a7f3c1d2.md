## Build Steps

### DEV-001 — CSV serialization with RFC 4180 quoting

`Status`: `DONE` `Depends On`: `NONE` `Acceptance`: `AC-001`

**Goal**

Turn a list of records into the CSV text the design defines.

**Affected Area**

New module `src/export.ts` (`csvCell`, `toCsv`), with unit tests in
`test/export.test.ts` as the self-check harness.

**Expected Outcome**

`toCsv(records)` returns the header row `id,title,owner,status,createdAt`
followed by one row per record in the given order, every row ending with CRLF.
`csvCell` encloses a value that contains a comma, double quote, CR, or LF in
double quotes and doubles each double quote inside it.

**Self-Check**

  `${COMMIT:Add CSV export of filtered records}`: exit 0; 21 passed, 0 failed.

### DEV-003 — Administrator-only export route

`Status`: `DONE` `Depends On`: `DEV-002` `Acceptance`: `AC-001, AC-002`

**Goal**

**Affected Area**

### DEV-004 — Command-line export

`Status`: `DONE` `Depends On`: `DEV-002` `Acceptance`: `AC-003`

**Goal**

Let an operator write an export from a shell on the service host.

**Affected Area**

`src/cli/export-records.ts` (`runExportRecords` and the direct-run entry

**Expected Outcome**
