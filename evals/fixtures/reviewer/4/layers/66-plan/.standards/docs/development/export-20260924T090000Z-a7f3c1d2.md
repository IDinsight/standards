### DEV-001 — CSV writer in the shared CSV module

`Status`: `PENDING` `Depends On`: `NONE` `Acceptance`: `AC-002`

**Goal**

Write rows of values as CSV text that `parseCsv` reads back unchanged.

**Affected Area**

`src/csv.js` (`csvField`, `formatCsv`; `parseCsv` untouched), with writer
scenarios in `test/export.test.js`.

**Expected Outcome**

`csvField` encloses a value containing a comma, double quote, CR, or LF in
double quotes and doubles each inner double quote; other values are written
unchanged. `formatCsv(rows)` joins fields with commas and ends every row,
including the last, with CRLF.

**Self-Check**

`npm test` in the project root.

### DEV-002 — Filtered export

`Status`: `PENDING` `Depends On`: `DEV-001` `Acceptance`: `AC-001, AC-002`

**Goal**

Produce the CSV for the records matching a filter.

**Affected Area**

New `src/export.js` (`exportRecords`, `EXPORT_COLUMNS`); `test/export.test.js`;
`package.json` (`test` script lists the new file).

**Expected Outcome**

loaded from `test/fixtures/records.csv` reproduces the file byte for byte.

**Self-Check**

`npm test` in the project root; confirm `src/import.js` and `parseCsv` are
unchanged.
