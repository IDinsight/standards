# Byte Helpers User Guide

## Goal

Give developers who use `bytesize` a short guide to formatting and parsing
byte sizes, so they can use the helpers without reading the source.

## Constraints

- Documentation-only cycle: edits are limited to a new `docs/guide.md` and a
  link to it from `README.md`. No source, test, or tooling changes.
- Examples describe the existing behavior of `src/bytes.js`.

## Non-goals

- Changing unit conventions, output format, or parsing rules.
- API reference generation or a documentation site.

## Work

### 1. User guide

**Intent:** Developers can learn how to import and call both helpers and what
to expect back.

**Done when:**

- `AC-001`: The guide's usage section includes a `formatBytes` example whose
  shown output is exactly what the current implementation returns for the
  shown input.
- `AC-002`: The guide is linked from `README.md`, and every relative link in
  `README.md` and the guide resolves to an existing repository file.
- `AC-003`: The guide states which errors `formatBytes` and `parseBytes` throw
  for invalid input, matching the current implementation.

**Depends on:** None
