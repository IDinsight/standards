## Build Steps

### DEV-001 — Batched CSV streaming with backpressure

`Status`: `DONE` `Depends On`: `NONE` `Acceptance`: `AC-001`

**Goal**

Render the export one batch of records at a time and write it to a stream
without overrunning the destination's buffer.

**Affected Area**

`src/export.ts` (`csvChunks`, `writeCsv`, `buildCsv`).

**Expected Outcome**

`csvChunks(source, batchSize)` yields the header and then one chunk per
1,000-record page; `writeCsv(source, out)` writes them to a `Writable`,
waiting for `drain` when `write` returns false, and resolves with the byte
count after the stream finishes. `buildCsv` produces the same CSV as before.

**Self-Check**

- `npm run typecheck` in the project root at commit
  `${COMMIT:Stream CSV export in batches}` (clean working tree, Node 22.18.0,
  TypeScript 5.6.3 from `npm install`): exit 0, no diagnostics.

**Implementation Notes**

`buildCsv` now joins the chunks from `csvChunks`, so existing callers get the
same string.
