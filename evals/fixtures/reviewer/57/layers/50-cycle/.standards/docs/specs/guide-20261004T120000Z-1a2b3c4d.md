# Technical Design

## Context

Documentation cycle for the existing `ledger-import` command. Behavior is
established from `.standards/CONTEXT.md` and direct inspection of
`bin/import.js`, `src/config.js`, and `src/parse.js`. No implementation change
is planned. No project references apply.

## Decision

Document the command as it runs today from the repository root
(`node bin/import.js`). The package `bin` entry is not documented as an
installed command, because the project is neither published nor linked. Treat
`src/config.js` as the source of truth for options and `src/parse.js` for input
and output.

## Acceptance Coverage

- `AC-001`: Invocation in `bin/import.js`; input contract in `parseLines`
  (three columns, header skipped unless `--no-header`, blank lines ignored, no
  quoted fields).
- `AC-002`: Option contract in `readConfig`, including `LEDGER_CURRENCY`
  precedence below `--currency`.
- `AC-003`: Output contract in `summarize` and the error handler in
  `bin/import.js`.
- `AC-004`: No architectural impact — a README pointer owned by Documenter.

## Interfaces and Contracts

- Command: `node bin/import.js <file> [--delimiter <char>] [--currency <code>]
  [--no-header]`; options may appear before or after the file.
- Defaults: delimiter `,`; currency from `LEDGER_CURRENCY` when set and
  non-empty, else `USD`; header row skipped.
- Validation: the delimiter must be exactly one character; unknown `--` options
  and a missing file argument are errors.
- Input: each non-empty line is split on the delimiter into date, description,
  amount; the amount is parsed with `Number` and rounded to integer cents. A
  non-numeric amount fails with `line N: invalid amount "<value>"`, where N
  counts non-empty lines including the header.
- Output: one line `{"currency":<code>,"count":<rows>,"totalCents":<sum>}` on
  stdout, exit status 0.
- Errors: `ledger-import: <message>` on stderr, exit status 1.

## Technical Acceptance Criteria

- `AC-002`: Every option accepted by `readConfig` appears in the guide with the
  default above; the guide lists no option that does not exist.
- `AC-003`: Output field names and the error prefix are quoted exactly as the
  code writes them.

## Risks and Follow-up

- `currency` labels the output only and does not convert amounts; the guide must
  not imply conversion.
