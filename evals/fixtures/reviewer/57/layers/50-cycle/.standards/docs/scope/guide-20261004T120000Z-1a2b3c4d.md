# Guide for the ledger-import command

## Goal

Team members who import bank statements currently have to read `src/` to learn
how to run `bin/import.js`. Give them a usage guide that describes the command's
existing behavior accurately, and make it easy to find.

## Constraints

- Documentation-only cycle: edits are limited to a new guide at
  `docs/importer.md` and a pointer in `README.md`.
- Describe current behavior only; examples must match what the command does
  today.

## Non-goals

- Changing the importer's behavior, options, tests, or package scripts.
- Supporting quoted CSV fields or currency conversion.
- Developer documentation of internal modules.

## Work

### 1. Usage guide

**Intent:** Let a reader run an import and understand its result without
reading the source.

**Done when:**

- `AC-001`: `docs/importer.md` lets a reader run an import from the repository
  root: prerequisites, the command, and the expected input columns and header
  handling, with a worked example.
- `AC-002`: The guide documents every command-line option and the
  `LEDGER_CURRENCY` environment variable, with defaults and precedence matching
  current behavior.
- `AC-003`: The guide describes the JSON summary written on success and the
  error behavior (message prefix and exit status).

**Depends on:** None

### 2. Discoverability

**Intent:** Readers of the README find the guide.

**Done when:**

- `AC-004`: `README.md` points readers to the guide.

**Depends on:** Work item 1.
