# CSV Export of Records

## Goal

Administrators of the records admin tool need to take the list they are
looking at, after filtering it by status, owner, or title text, into a
spreadsheet. The service should produce that list as a CSV file that
spreadsheet programs read correctly even when titles contain commas, quotes,
or line breaks, and the user guide should tell administrators how to do it.

## Constraints

- An export applies the same filters, with the same validation, as listing
  records (`GET /records`).
- Listing records keeps its current behavior.

## Non-goals

- Formats other than CSV, choosing or reordering columns, and scheduled or
  emailed exports.
- Listing or removing previously created export files.
- Changes to the admin tool's front end.
- Deciding or changing who may export. Export permissions for the admin tool
  are being settled in a separate permissions review; the export's existing
  administrator check stays as built.

## Work

### 1. Filtered CSV export

**Intent:** Let administrators save exactly the records they filtered as a
CSV file.

**Done when:**

- `AC-001`: Administrators can export the currently filtered records as CSV; a field containing a comma, double quote, or newline is quoted per RFC 4180, with embedded double quotes doubled.

**Depends on:** None

### 2. Export instructions in the user guide

**Intent:** Let administrators learn how to export from the guide they
already use for listing and filtering records.

**Done when:**

- `AC-004`: The user guide (`docs/usage.md`) explains how an administrator exports the filtered records as CSV, including which filters apply and what the export returns.

**Depends on:** 1

## Retired Acceptance Identifiers

- `AC-002`: Retired by the request change in this cycle. It required export requests from non-administrators or from no signed-in user to be denied by server-side authorization before any export file is created; export permissions are now settled in a separate permissions review, so access is no longer a condition of this cycle.
- `AC-003`: Retired before this revision was completed. It placed the export instructions in the README; replaced by AC-004 after the user chose the user guide.

## Assumptions

- Export files are kept by the service; how the admin tool offers them for
  download is outside this repository.
