## Build Steps

### DEV-001 — Export schema migration

`Status`: `PENDING` `Depends On`: `NONE` `Acceptance`: `AC-001`

**Goal**

Add the storage for export runs.

**Affected Area**

New `migrations/002_export_runs.sql`.

**Expected Outcome**

After `npm run db:migrate`, the database has an `export_runs` table and a
nullable `invoices.export_run_id` column referencing it, as the design's
schema contract defines; existing invoices have `export_run_id` NULL.

**Self-Check**

Inspect the migration against the design's schema contract; run
`npm run db:migrate` and `npm run test:db` when a libSQL server is available.

### DEV-002 — CSV formatting

`Status`: `PENDING` `Depends On`: `NONE` `Acceptance`: `AC-001`

**Goal**

Turn a list of invoices into the CSV the design defines.

**Affected Area**

New `src/exports/csv.js` (`formatAmount`, `toCsv`), with unit tests in
`test/exports.csv.test.js` as the self-check harness.

**Expected Outcome**

`toCsv(invoices)` returns the header `invoice_id,customer,amount,issued_on`
and one CRLF-terminated row per invoice in the given order, with amounts in
currency units with two decimals and RFC 4180 quoting.

**Self-Check**

`npm test` in the project root.

### DEV-003 — Transactional export run

`Status`: `PENDING` `Depends On`: `DEV-001, DEV-002` `Acceptance`: `AC-001, AC-002`

**Goal**

Run an export as one database transaction.

**Affected Area**

New `src/exports/repository.js` (`pendingInvoices`, `insertRun`,
`markExported`, `ExportConflictError`) and `src/exports/service.js`
(`runExport`).

**Expected Outcome**

`runExport(db, { now })` selects the pending invoices, inserts the run, marks
each invoice with the run's id, and returns `{ runId, invoiceCount, csv }`, or
`null` when nothing is pending, all inside `db.transaction()`. Any failure,
including an invoice already marked by another run, rolls the transaction back
and is rethrown.

**Self-Check**

`npm test`; inspect that every statement goes through the transaction handle;
run `npm run test:db` when a libSQL server is available.
