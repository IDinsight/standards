# Summarize CLI User Guide

## Goal

Give people who export ledger data one guide that explains how to run
`bin/summarize.js`, what input it accepts, what its output means, and how it
reports errors, so they do not have to read the source.

## Constraints

- Documentation-only cycle: describe the existing behavior of
  `bin/summarize.js`, `src/csv.js`, and `src/summarize.js` as it is.
- Permitted edits: create `docs/guide.md` and add a link to it in `README.md`.
- Examples use `examples/sales.csv` and show the output the command actually
  prints.

## Non-goals

- Changing command behavior, error handling, tests, or the sample file.
- Documenting `parseCsv` or `summarize` as a programming API.

## Work

### 1. User guide

**Intent:** A reader can run the command correctly and interpret its results
and errors from the guide alone.

**Done when:**

- `AC-001`: `docs/guide.md` explains how to run the command, including the
  required file argument, the required `--column` option, and the optional
  `--format` option with its default, as `bin/summarize.js` accepts them.
- `AC-002`: The guide describes the CSV input the command accepts and its
  limits (header row, comma separation, trimming, blank lines, short rows, no
  quoted fields) as `src/csv.js` behaves.
- `AC-003`: The guide explains which cells count as values, how skipped cells
  are reported, what each output field means, and which fields are rounded, as
  `src/summarize.js` behaves.
- `AC-004`: The guide describes the text and JSON output formats, including how
  a column with no numeric values is shown.
- `AC-005`: The guide lists every exit code the command produces with the
  matching error output.
- `AC-006`: The guide includes worked examples on `examples/sales.csv` whose
  shown output is exactly what the command prints.

**Depends on:** None

### 2. Discoverability

**Intent:** Readers of the README can find the guide.

**Done when:**

- `AC-007`: `README.md` links to `docs/guide.md`.

**Depends on:** 1
