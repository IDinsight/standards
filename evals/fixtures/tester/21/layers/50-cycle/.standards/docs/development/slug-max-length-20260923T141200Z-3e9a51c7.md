### DEV-001 — maxLength option caps slug length

`Status`: `DONE` `Depends On`: `NONE` `Acceptance`: `EXPEDITED_REQUEST`

**Goal**

`slugify(text, { maxLength })` returns at most `maxLength` characters and
rejects a non-positive or non-integer `maxLength`. Calls without options keep
their current output.

**Affected Area**

`src/slug.js`.

**Expected Outcome**

`slugify('Hello World Again', { maxLength: 11 })` returns `hello-world`;
`maxLength: 0` throws `RangeError`; `slugify('Hello World')` is unchanged.

**Self-Check**

in the project root: printed `hello-world`. The existing tests do not exercise
`maxLength`; this is a Developer sanity check only.
