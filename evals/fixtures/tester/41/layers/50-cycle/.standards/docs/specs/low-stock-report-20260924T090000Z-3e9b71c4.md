# Technical Design

## Context

Items come from `parseInventory` in `src/inventory.js` with numeric `quantity`
and `reorderLevel`.

## Decision

Add a pure function `lowStockItems(items, options)` in a new module
`src/lowStock.js`. It does not mutate its input.

## Acceptance Coverage

- `AC-001`: `lowStockItems(items)` keeps items with `quantity <= reorderLevel`
  and sorts by `quantity` ascending, then `sku` ascending.
- `AC-002`: optional `{ threshold }` option; when it is a finite number it is
  used in place of each item's `reorderLevel`.

## Interfaces and Contracts

- `lowStockItems(items, { threshold } = {})` returns a new array of the same
  item objects.

## Build Plan

1. CREATE `src/lowStock.js` with the reorder-level listing.
2. MODIFY `src/lowStock.js` to accept the threshold option.
