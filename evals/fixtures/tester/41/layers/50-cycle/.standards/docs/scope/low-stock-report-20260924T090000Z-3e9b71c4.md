# Low-Stock Listing

## Goal

Warehouse staff need a list of items that should be reordered, so they can act
on the lowest stock first.

## Non-goals

- Placing orders or contacting suppliers.
- Changes to CSV parsing.

## Work

### 1. Low-stock listing

**Intent:** Show which items need reordering, most urgent first.

**Done when:**

- `AC-001`: The listing contains every item whose quantity is at or below its
  reorder level, and no other item, ordered by quantity ascending (ties by SKU).
- `AC-002`: A caller can supply one threshold that replaces every item's
  reorder level for that listing.

**Depends on:** None
