# Technical Design

## Context

The notes routes live in `app/notes/router.py` and receive the note store
through `Depends(get_note_store)`. `app/llm/client.py` already provides
`LLMClient.summarize(text, max_words=80) -> str`, the `get_llm_client`
dependency, and nine `LLMError` subclasses; no route uses it yet. The FastAPI
interface is the vendored subset in `vendor/fastapi/`, which supports path
parameters, `Depends`, `HTTPException` with headers, and
`app.dependency_overrides`.

## Decision

Add a `summarize_note` handler to the existing notes router. It receives the
store and the LLM client as dependencies, looks the note up, passes the note
text to `LLMClient.summarize`, and returns the client's string unchanged. A
timeout maps to 503 with a retry message and a `Retry-After` header; every
other client error maps to 502. The client and its configuration do not
change.

## Acceptance Coverage

- `AC-001`: `POST /notes/{note_id}/summary` handler in `app/notes/router.py`
  returning `{"note_id": <int>, "summary": <str>}`, where `summary` is the
  value returned by `LLMClient.summarize(note.text)`.
- `AC-002`: the handler catches `LLMTimeoutError` and raises `HTTPException`
  with status 503, the retry detail below, and `Retry-After: 5`.

## Interfaces and Contracts

`POST /notes/{note_id}/summary`, no request body:

- Note exists and the client returns a string: 200,
  `{"note_id": <id>, "summary": <client string>}`.
- Note does not exist: 404, `{"detail": "Note not found"}`; the client is not
  called.
- Client raises `LLMTimeoutError`: 503,
  `{"detail": "The summary service timed out. Please retry in a few seconds."}`,
  header `Retry-After: 5`.
- Client raises any other `LLMError` subclass: 502,
  `{"detail": "The summary could not be generated."}`.

## Technical Acceptance Criteria

- `AC-001`: For an existing note, the response is 200 and `summary` equals the
  string the client returned for that note's text.
- `AC-002`: On `LLMTimeoutError` the response is 503, its `detail` tells the
  caller to retry, and it carries `Retry-After: 5`; the exception does not
  escape the handler.
