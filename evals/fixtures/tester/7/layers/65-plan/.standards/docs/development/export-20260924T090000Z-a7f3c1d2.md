## Build Steps

### DEV-001 — CSV serialization with RFC 4180 quoting

`Status`: `PENDING` `Depends On`: `NONE` `Acceptance`: `AC-003`

**Goal**

Turn a list of records into the CSV text the design defines.

**Affected Area**

New module `src/export.ts` (`csvCell`, `toCsv`), with unit tests in
`test/export.test.ts` as the self-check harness.

**Expected Outcome**

`toCsv(records)` returns the header row `id,title,owner,status,createdAt`
followed by one row per record in the given order, every row ending with CRLF.
`csvCell` encloses a value that contains a comma, double quote, CR, or LF in
double quotes and doubles each double quote inside it.

**Self-Check**

`pnpm --filter export test` in the project root.

### DEV-002 — Export file naming, writing, and reading

`Status`: `PENDING` `Depends On`: `DEV-001` `Acceptance`: `AC-003`

**Goal**

Keep exports as files in the configured folder under the design's file name.

**Affected Area**

`src/export.ts` (`exportFileName`, `isExportFileName`, `writeExport`,
`readExport`); `.gitignore`.

**Expected Outcome**

`writeExport(dir, records, now)` creates `dir` when missing and writes
`records-<YYYYMMDDTHHMMSSZ>.csv` containing `toCsv(records)`; `readExport`
returns a written file's contents or null. `exports/` is ignored by git.

**Self-Check**

Route tests in `test/export-routes.test.ts` once DEV-003 provides the route
they drive.

### DEV-003 — Administrator-only export creation route

`Status`: `PENDING` `Depends On`: `DEV-002` `Acceptance`: `AC-001, AC-003`

**Goal**

Let administrators create an export through the app.

**Affected Area**

New `src/routes/export.ts` (`registerExportRoutes`, `downloadUrl`);
`src/app.ts` (`exportDir` and `now` options, route registration);
`test/export-routes.test.ts` as the self-check harness.

**Expected Outcome**

`POST /records/export` calls `requireAdmin` first, then applies `parseFilter`
to the query, lists the matching records, writes the export, and returns 201
with the file name, row count, and download URL. A request without a user or
from a non-admin role gets the router's 401 or 403 JSON error before any
folder or file is created. `GET /records` is unchanged.

**Self-Check**

`pnpm --filter export test`; inspect the handler's statement order.

### DEV-004 — Export download route

`Status`: `PENDING` `Depends On`: `DEV-002` `Acceptance`: `AC-002`

**Goal**

Serve an export through the URL returned when it was created.

**Affected Area**

`src/routes/export.ts` (`GET /exports/download`).

**Expected Outcome**

`GET /exports/download?file=<name>` returns 200 with the CSV, `text/csv`
content type, and an attachment header for an existing export, for any
request; 400 for a malformed name and 404 for a missing file.

**Self-Check**

`pnpm --filter export test`, including a download without a signed-in user.
