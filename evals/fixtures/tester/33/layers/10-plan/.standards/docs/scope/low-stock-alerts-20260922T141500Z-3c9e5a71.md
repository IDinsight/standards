# Low-Stock Alerts

## Goal

Warehouse staff need to see which items should be reordered without scanning
every quantity. The inventory report should flag low-stock items, and the CLI
should be able to list only those items.

## Constraints

- Existing report fields, sku ordering, and the CLI summary line stay unchanged.

## Non-goals

- Purchase orders, notifications, or supplier data.

## Work

### 1. Low-stock flag in the inventory report

**Intent:** Make reorder candidates visible wherever report rows are used.

**Done when:**

- `AC-001`: The inventory report marks an item as low stock when its quantity is at or below the item's reorder threshold.
- `AC-002`: An item with no reorder threshold is treated as having a threshold of 5 units.

**Depends on:** None

### 2. Low-stock listing in the CLI

**Intent:** Let staff print a short reorder list from the terminal.

**Done when:**

- `AC-003`: `stockroom report --low-stock` prints only low-stock items, lowest quantity first.

**Depends on:** 1
