### DEV-001 — Batched streaming of listing results

`Status`: `PENDING` `Depends On`: `NONE` `Acceptance`: `EXPEDITED_REQUEST`

**Goal**

Read listing results in batches instead of fetching every matching row at once.

**Affected Area**

New `app/streaming.py` (`iter_records`), built on `list_query` in
`app/repository.py`; `tests/integration/test_streaming_db.py` as the
self-check harness.

**Expected Outcome**

`iter_records(conn, record_filter, batch_size)` yields the same records as
`list_records` for the filter, in id order, fetching `batch_size` rows at a
time through a named server-side cursor.

**Self-Check**

`python -m pytest -m "not integration"` and, with the compose database,
`python -m pytest -m integration` in the project root.
