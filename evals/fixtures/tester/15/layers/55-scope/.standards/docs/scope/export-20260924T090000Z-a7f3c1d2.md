# CSV Export of Records

## Goal

Administrators of the records admin tool need to take the list they are
looking at, after filtering it by status, owner, or title text, into a
spreadsheet. The service should produce that list as a CSV file that
spreadsheet programs read correctly even when titles contain commas, quotes,
or line breaks. Export files hold record data, so only administrators may
create them.

The people who run the service also need written instructions for exports,
because export files are kept on the service host and the service never
cleans them up.

## Constraints

- An export applies the same filters, with the same validation, as listing
  records (`GET /records`).
- Access is decided by the service, not by the admin tool's user interface.
- Listing records keeps its current behavior.

## Non-goals

- Formats other than CSV, choosing or reordering columns, and scheduled or
  emailed exports.
- Listing or removing previously created export files through the service.
- Changes to the admin tool's front end.

## Work

### 1. Filtered CSV export

**Intent:** Let administrators save exactly the records they filtered as a
CSV file, and nobody else.

**Done when:**

- `AC-001`: An administrator can export the currently filtered records as a CSV file in which any field containing a comma, double quote, or newline is quoted per RFC 4180 with embedded double quotes doubled; export requests from other roles or without a signed-in user are refused without creating a file.

**Depends on:** None

### 2. Operations guide for exports

**Intent:** Operators can run and look after exports without reading the
code.

**Done when:**

- `AC-002`: Before the change is offered for sign-off, an operations guide in the repository explains who can run an export and how, which filters apply, where export files are written and how they are named, and that the service never removes them.

**Depends on:** 1

## Assumptions

- Export files are kept by the service; how the admin tool offers them for
  download is outside this repository.
