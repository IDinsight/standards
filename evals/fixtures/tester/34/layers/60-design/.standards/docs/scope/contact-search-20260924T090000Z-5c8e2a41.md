# Contact Search

## Goal

Let callers of the contacts library find contacts by part of their name or
email address instead of scanning the full list themselves.

## Constraints

- Search works over the in-memory directory created by `createDirectory`.
- The library keeps having no dependencies.

## Non-goals

- Fuzzy matching, ranking, or pagination.
- Searching fields other than name and email.

## Work

### 1. Name search

**Intent:** Support staff usually remember part of a contact's name.

**Done when:**

- `AC-001`: Searching with a text fragment returns every contact whose name
  contains the fragment, ignoring letter case, in directory order.

**Depends on:** None

### 2. Email search

**Intent:** Inbound messages identify people by address.

**Done when:**

- `AC-002`: Searching with a text fragment also returns every contact whose
  email address contains the fragment, ignoring letter case, listing each
  matching contact once, in directory order.

**Depends on:** 1

### 3. Empty queries

**Intent:** An empty search box must not dump the whole directory.

**Done when:**

- `AC-003`: A blank or whitespace-only query returns no contacts.

**Depends on:** None
