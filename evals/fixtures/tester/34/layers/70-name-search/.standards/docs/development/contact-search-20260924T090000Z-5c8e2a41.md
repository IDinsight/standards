## Build Steps

### DEV-001 — Name search with query normalization

`Status`: `DONE` `Depends On`: `NONE` `Acceptance`: `AC-001, AC-003`

**Goal**

Provide `searchContacts(directory, query)` matching contact names under the
design's matching rule, including the blank-query rule.

**Affected Area**

New `src/search.js`; export added to `src/index.js`.

**Expected Outcome**

`searchContacts` returns, in directory order, the contacts whose name contains
the trimmed query ignoring case, and an empty list for a blank or
whitespace-only query. Email addresses are not matched yet.

**Self-Check**

- `node --test test/directory.test.js test/format.test.js` in the project root,
  on the working tree with `src/search.js` and the new export (before the
  commit that added them): exit 0, 5 passed, 0 failed.
- A `node -e` call against a two-contact directory built with
  `createDirectory` returned `Ada Lovelace` for the query `LOVE` and an empty
  list for a whitespace-only query.

**Implementation Notes**

Linear scan of `directory.list()` as the design specifies; no index.
