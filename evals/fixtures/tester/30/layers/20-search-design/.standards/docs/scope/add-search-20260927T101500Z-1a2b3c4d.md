# Contact Search

## Goal

Let callers of the contacts library find contacts by typing part of a name or
an email address, instead of filtering `list()` themselves.

## Constraints

- The existing `Directory`, `loadDirectory`, and `saveDirectory` behavior is
  unchanged.
- No new runtime dependencies.

## Non-goals

- Fuzzy or typo-tolerant matching.
- Searching fields other than name and email.
- Paging or result limits.

## Work

### 1. Search contacts

**Intent:** Callers can look up contacts from partial input such as a search
box.

**Done when:**

- `AC-001`: Searching for part of a contact's name returns that contact,
  ignoring letter case.
- `AC-002`: Searching for part of a contact's email address returns that
  contact, ignoring letter case.
- `AC-003`: Search results are ordered by name, and a blank or
  whitespace-only query returns no contacts.

**Depends on:** None
