### DEV-001 — Quote line breaks in shared CSV cells

`Status`: `DONE` `Depends On`: `NONE` `Acceptance`: `AC-001`

**Goal**

Extend the shared quoting rule in `src/csv.ts` to RFC 4180.

**Affected Area**

`src/csv.ts` (`NEEDS_QUOTES`, used by `escapeCell` and `formatRow`).

**Expected Outcome**

`escapeCell` quotes a value containing a comma, double quote, CR, or LF and
doubles the quotes inside it; other values are unchanged.

**Self-Check**

- `pnpm test` in the project root at commit
  `${COMMIT:Add CSV export of filtered records}` (clean tree, Node 22,
  offline): exit 0; 11 tests passed, 0 failed.
- Correction: at commit `${COMMIT:Quote carriage returns in CSV cells}`,
  `node --test --test-name-pattern "bare carriage return" test/export.test.ts`
  in the project root: exit 0; 1 passed, 0 failed.

**Implementation Notes**

Reopened for the IMPLEMENTATION failure from Testing: `NEEDS_QUOTES` matched
LF but not a bare CR. It is now `/[",\r\n]/`; marked DONE again after the
self-check.
