# CSV Export of Records

## Goal

Administrators need the records they filtered by status or owner as a CSV
file that spreadsheet programs read correctly even when titles contain
commas, quotes, or line breaks. Exported record data is limited to
administrators.

## Constraints

- An export uses the same filters and validation as `GET /records`.
- Access is decided by the service.
- Listing records and bulk import keep their current behavior.

## Non-goals

- Other formats, column selection, and changes to bulk import or the front
  end.

## Work

### 1. Filtered CSV export

**Intent:** Let administrators download exactly the records they filtered.

**Done when:**

- `AC-001`: Administrators can export the currently filtered records as CSV; a field containing a comma, double quote, carriage return, or line feed is quoted per RFC 4180, with embedded double quotes doubled.

**Depends on:** None

### 2. Administrator-only access

**Intent:** Keep exported record data limited to administrators.

**Done when:**

- `AC-002`: An export request from a user who is not an administrator, or from no signed-in user, is denied by server-side authorization and receives no record data.

**Depends on:** 1
