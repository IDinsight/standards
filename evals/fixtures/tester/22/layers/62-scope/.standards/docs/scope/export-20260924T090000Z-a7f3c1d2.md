# Semicolon Delimiter for CSV Exports

## Goal

Spreadsheet programs set to several European locales used by the admin teams
expect semicolon-separated files and put each comma-separated row into a
single column. The export library should be able to produce semicolon-separated
CSV for those callers, while every existing caller keeps receiving exactly the
comma-separated output it gets today.

## Constraints

- Callers that do not ask for a delimiter see no change in output.
- Column names and order, row order, and CRLF row endings stay as they are.

## Non-goals

- Delimiters other than comma and semicolon, including tab-separated output.
- Choosing the delimiter from a user's locale; the calling service decides.
- Changes to export file names.

## Work

### 1. Semicolon-separated output

**Intent:** Let callers produce CSV that semicolon-locale spreadsheets split
into columns correctly.

**Done when:**

- `AC-001`: Records exported with the semicolon delimiter have every field, including the header row, separated by `;`; a field containing `;`, a double quote, or a line break is enclosed in double quotes with embedded double quotes doubled.

**Depends on:** None

### 2. Comma remains the default

**Intent:** Keep existing callers working without changes.

**Done when:**

- `AC-002`: Exports that do not request a delimiter keep the existing comma-separated format, including its quoting of fields that contain commas, double quotes, or line breaks.

**Depends on:** None

## Assumptions

- The admin service chooses which delimiter to request; no caller changes are
  part of this repository.
