# JSON Export Format

## Goal

Warehouse staff feed inventory exports into scripts that expect JSON. Let
`inventory export` produce JSON as well as CSV, and document in the user guide
how to choose the format.

## Constraints

- CSV remains the default output, and existing CSV output must not change.
- The command stays `inventory export <file>`; the format is an option.

## Non-goals

- Other formats such as XML, YAML, or spreadsheets.
- Changing the inventory file format or the exported columns.

## Work

### 1. JSON output

**Intent:** Scripts can consume exports directly without parsing CSV.

**Done when:**

- `AC-001`: `inventory export <file> --format json` writes a JSON array with
  one object per item containing exactly `sku`, `name`, `quantity` (a number),
  and `location`, and exits 0; without `--format` the output is the unchanged
  CSV.

**Depends on:** None

### 2. User guide

**Intent:** Staff learn about the option from the user guide rather than from
the source.

**Done when:**

- `AC-002`: The user guide at `docs/export.md` explains how to choose the
  export format and shows a JSON example that matches the command's actual
  output.

**Depends on:** 1

### 3. Unsupported formats

**Intent:** A mistyped format fails clearly instead of producing unexpected
output.

**Done when:**

- `AC-003`: An unsupported `--format` value exits with status 2, writes an
  error naming the supported formats to stderr, and writes nothing to stdout.

**Depends on:** 1
