`Status`: `DONE` `Depends On`: `NONE` `Acceptance`: `AC-001`

**Goal**

**Affected Area**

`src/export.js`

**Expected Outcome**

uncommitted change: exit 0, 4 passed. `node bin/inventory.js export

### DEV-002 — `--format` option on `inventory export`

`Status`: `DONE` `Depends On`: `DEV-001` `Acceptance`: `AC-001, AC-003`

**Goal**

Accept `--format <name>` and `--format=<name>`, default `csv`, and reject
unknown names before reading the input.

**Affected Area**

`src/cli.js`

**Expected Outcome**

The selected formatter writes stdout; an unknown name writes
`Unknown format "<name>". Supported formats: csv, json.` to stderr and returns
2 without reading the file; a missing option value or extra argument prints the
usage text and returns 2.

**Self-Check**

`node --test test/export.test.js test/cli.test.js` in the project root on the
uncommitted change: exit 0, 4 passed. `node bin/inventory.js export
data/sample.json --format xml` printed the unknown-format message and exited 2;
without `--format` the output matched the previous CSV.
