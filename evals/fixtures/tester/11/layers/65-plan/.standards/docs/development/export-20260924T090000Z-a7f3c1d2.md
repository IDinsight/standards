## Build Steps

### DEV-001 — CSV serialization with quoting and empty fields

`Status`: `PENDING` `Depends On`: `NONE` `Acceptance`: `AC-001, AC-003`

**Goal**

Turn a list of records into the CSV text the design defines.

**Affected Area**

New module `src/export.ts` (`csvCell`, `toCsv`).

**Expected Outcome**

`toCsv(records)` returns the header row `id,title,owner,status,createdAt`
followed by one row per record in the given order, every row ending with CRLF.
`csvCell` encloses a value that contains a comma, double quote, CR, or LF in
double quotes and doubles each double quote inside it; `null` and `undefined`
become an empty field; other values are written unchanged.

**Self-Check**

`pnpm --filter export test` in the project root for regressions, plus a
`node -e` sanity run of `toCsv` on the seed records and on records with a
`null` value and a missing property.

### DEV-002 — Export file naming and writing

`Status`: `PENDING` `Depends On`: `DEV-001` `Acceptance`: `AC-001`

**Goal**

Write an export to the configured folder under the design's file name.

**Affected Area**

`src/export.ts` (`exportFileName`, `writeExport`); `.gitignore`.

**Expected Outcome**

`writeExport(dir, records, now)` creates `dir` when missing, writes
`records-<YYYYMMDDTHHMMSSZ>.csv` (UTC time of `now`) containing
`toCsv(records)`, and returns the file name, path, and CSV text. `exports/` is
ignored by git.

**Self-Check**

`node -e` run of `writeExport` into a temporary folder; compare the file with
`toCsv` output; `git check-ignore` on a path under `exports/`.

### DEV-003 — Administrator-only export route

`Status`: `PENDING` `Depends On`: `DEV-002` `Acceptance`: `AC-001, AC-002`

**Goal**

Expose the export through the app to administrators only.

**Affected Area**

New `src/routes/export.ts` (`registerExportRoutes`); `src/app.ts`
(`exportDir` and `now` options, route registration).

**Expected Outcome**

`POST /records/export` calls `requireAdmin` first, then applies `parseFilter`
to the query, lists the matching records, writes the export, and returns 201
with `content-type: text/csv; charset=utf-8`, a `content-disposition`
attachment header naming the file, and the CSV as the body. A request without
a user or from a non-admin role gets the router's 401 or 403 JSON error before
any folder or file is created. `GET /records` is unchanged.

**Self-Check**

`pnpm --filter export test`; a `node -e` run of `createApp` with a temporary
`exportDir` for admin, anonymous, and viewer requests; inspect the handler's
statement order.
