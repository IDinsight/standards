## Build Steps

### DEV-001 — CSV serialization with quoting and empty fields

`Status`: `DONE` `Depends On`: `NONE` `Acceptance`: `AC-001, AC-003`

**Goal**

Turn a list of records into the CSV text the design defines.

**Affected Area**

New module `src/export.ts` (`csvCell`, `toCsv`).

**Expected Outcome**

`toCsv(records)` returns the header row `id,title,owner,status,createdAt`
followed by one row per record in the given order, every row ending with CRLF.
`csvCell` encloses a value that contains a comma, double quote, CR, or LF in
double quotes and doubles each double quote inside it; `null` and `undefined`
become an empty field; other values are written unchanged.

**Self-Check**

- `pnpm --filter export test` in the project root at commit
  `${COMMIT:Add CSV export of filtered records}` (clean working tree, Node 22,
  offline): exit 0; 16 tests passed, 0 failed (existing suites; this step
  adds no tests).
- `node -e` in the project root importing `src/export.ts` at that commit:
  `toCsv` on the six seed records plus a record with `title: null` and a
  record without an `owner` property printed the header, the quoted titles of
  records 1 and 3, and empty fields for the two missing values; every row
  ended with CRLF.

### DEV-003 — Administrator-only export route

`Status`: `DONE` `Depends On`: `DEV-002` `Acceptance`: `AC-001, AC-002`

**Goal**

Expose the export through the app to administrators only.

**Affected Area**

New `src/routes/export.ts` (`registerExportRoutes`); `src/app.ts`
(`exportDir` and `now` options, route registration).

**Expected Outcome**

`POST /records/export` calls `requireAdmin` first, then applies `parseFilter`
to the query, lists the matching records, writes the export, and returns 201
with `content-type: text/csv; charset=utf-8`, a `content-disposition`
attachment header naming the file, and the CSV as the body. A request without
a user or from a non-admin role gets the router's 401 or 403 JSON error before
any folder or file is created. `GET /records` is unchanged.

**Self-Check**

- `pnpm --filter export test` in the project root at commit
  `${COMMIT:Add CSV export of filtered records}`: exit 0; 16 tests passed,
  0 failed.
- `node -e` importing `src/app.ts` at that commit with a temporary
  `exportDir`: an admin request returned 201 with
  `text/csv; charset=utf-8` and one file written; a request without a user
  returned 401 and a viewer request 403, and no folder was created for either.
- Inspection of `src/routes/export.ts` at that commit:
  `requireAdmin(request.user)` is the handler's first statement, ahead of
  `parseFilter`, `store.list`, and `writeExport`.
