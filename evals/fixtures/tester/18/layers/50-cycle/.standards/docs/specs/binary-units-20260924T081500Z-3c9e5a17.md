# Technical Design

## Context

`formatBytes` in `src/format.js` divides by 1000 and labels with a fixed
decimal unit list. `src/cli.js` filters out `--` arguments and formats the rest.

## Decision

Add an optional `binary` boolean to the existing options object of
`formatBytes`, defaulting to `false`. Select a `{ base, units }` table from it
and keep the existing loop and number formatting. The CLI reads a `--binary`
flag and passes it through. No new modules or dependencies.

## Acceptance Coverage

- `AC-001`: `binary: true` selects base 1024 and units B, KiB, MiB, GiB, TiB in `formatBytes`.
- `AC-002`: `binary` defaults to `false`, which selects the existing base 1000 table and formatting.
- `AC-003`: `src/cli.js` detects `--binary` and calls `formatBytes(value, { binary })`.

## Interfaces and Contracts

- `formatBytes(bytes, { digits = 1, binary = false } = {})`; return format
  `<value> <unit>` unchanged. Input validation (`RangeError`) is unchanged.
- CLI: `bytefmt [--binary] <bytes>...`; flags may appear anywhere in the
  argument list.

## Technical Acceptance Criteria

- `AC-001`: values below 1024 print as whole bytes with `B`; values at or above 1024 are divided by 1024 per step and printed with `toFixed(digits)`; the largest unit is TiB.
- `AC-002`: for every input, the result without `binary` equals the result with `binary: false`.
- `AC-003`: the CLI exit status and usage behavior for a missing argument are unchanged.

## Build Plan

1. Unit tables and the `binary` option in `src/format.js`.
2. `--binary` flag in `src/cli.js`.
