# Binary Units

## Goal

Let callers and CLI users show sizes in binary (1024-based) units, as many
operating-system tools do, without changing the existing decimal output.

## Constraints

- Existing callers of `formatBytes` and the `bytefmt` command must see the same
  output as before unless they opt in.

## Non-goals

- Parsing human-readable sizes back into numbers.
- Locale-specific number formatting.

## Work

### 1. Binary units in the library

**Intent:** Library callers can choose binary units.

**Done when:**

- `AC-001`: `formatBytes(n, { binary: true })` steps by 1024 and labels values with B, KiB, MiB, GiB, or TiB, using the same number formatting as decimal output.
- `AC-002`: Calling `formatBytes` without the `binary` option produces exactly the same output as before this change.

**Depends on:** None

### 2. Binary units in the CLI

**Intent:** Command-line users can choose binary units.

**Done when:**

- `AC-003`: `bytefmt --binary <bytes>...` prints each value in binary units; without the flag, output is unchanged.

**Depends on:** 1
