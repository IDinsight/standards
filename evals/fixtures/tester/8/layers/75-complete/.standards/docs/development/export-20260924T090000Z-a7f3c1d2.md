## Build Steps

### DEV-001 — CSV serialization and export file name

`Status`: `DONE` `Depends On`: `NONE` `Acceptance`: `AC-001`

**Goal**

Turn a list of records into the CSV text the design defines and name the
export file.

**Affected Area**

New module `src/export.ts` (`csvCell`, `toCsv`, `exportFileName`), with unit
tests in `test/export.test.ts` as the self-check harness.

**Expected Outcome**

`toCsv(records)` returns the header row `id,title,owner,status,createdAt`
followed by one row per record in the given order, every row ending with CRLF.
`csvCell` encloses a value that contains a comma, double quote, CR, or LF in
double quotes and doubles each double quote inside it; other values are
written unchanged. `exportFileName(now)` returns
`records-<YYYYMMDDTHHMMSSZ>.csv` in UTC.

  Node 22, offline): exit 0; 27 tests passed, 0 failed, including the five

### DEV-002 — Document archive client

`Status`: `DONE` `Depends On`: `NONE` `Acceptance`: `AC-001, AC-003`

**Goal**

Upload a CSV file to the document archive.

**Affected Area**

New module `src/archive.ts` (`createArchiveClient`, `ArchiveError`,
`ArchiveTimeoutError`).

**Expected Outcome**

`put(name, csv, timeoutMs)` sends `PUT <base>/files/<name>` with the CSV body
and resolves with the archive's `location` on 201. Any other status rejects
with an `ArchiveError` carrying the status; a request that fails without a
response rejects with status `null`; a request still running after
`timeoutMs` is abandoned and rejects with `ArchiveTimeoutError`.

**Self-Check**

- `pnpm --filter export test` in the project root at commit
  `${COMMIT:Add CSV export to the document archive}`: exit 0; 27 tests
  passed. The client is driven through the route tests in
  `test/export-route.test.ts` with a stand-in `send` function (201, 503, 400,
  and a request that never answers).

### DEV-003 — Administrator-only export route

`Status`: `DONE` `Depends On`: `DEV-001, DEV-002` `Acceptance`: `AC-001, AC-002, AC-003`

**Goal**

Expose the export through the app to administrators only.

**Affected Area**

New `src/routes/export.ts` (`registerExportRoutes`); `src/http/router.ts`
(promise-returning handlers); `src/app.ts` (`archive`, `exportTimeoutMs`,
`retryDelayMs`, and `now` options, route registration);
`test/export-route.test.ts` as the self-check harness.

**Expected Outcome**

`POST /records/export` calls `requireAdmin` first, then applies `parseFilter`
to the query, lists the matching records, and uploads the CSV. Archive errors
with a 5xx status or no status are retried after `retryDelayMs`; an upload
abandoned for running past `exportTimeoutMs` gives 504
`{"error": "export did not complete"}`; other archive errors give 502. Success
returns 201 with `{fileName, location, count}`. A request without a user or
from a non-admin role gets 401 or 403 before the archive is contacted.
Synchronous handlers and `GET /records` are unchanged.

**Self-Check**

- `pnpm --filter export test` in the project root at commit
  `${COMMIT:Add CSV export to the document archive}`: exit 0; 27 tests
  passed, 0 failed. The six route tests cover an administrator export, 401
  and 403 with no archive request, a 503 followed by a stored file, 504 when
