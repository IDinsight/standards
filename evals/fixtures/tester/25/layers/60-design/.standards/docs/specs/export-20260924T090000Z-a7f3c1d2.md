# Technical Design

## Context

Per `.standards/CONTEXT.md`, the CLI requires `--output`, prints its summary
on standard output, and lets exceptions escape. The web page is plain ES
modules whose components take the `document` they render into.

## Decision

CLI: `--output` defaults to `-` (standard output); input problems become a
`RecordsError` that `main` reports as one line on standard error with exit
status 1; usage errors stay with argparse (exit status 2). The CSV text is
built before any output file is opened.

Web: a new `createExportControl` component owns the button and its error
message; `main.js` mounts it in `#toolbar`. The button stays a native,
always-focusable `<button>`: while a request is in flight it carries
`aria-disabled="true"` and ignores activation instead of using `disabled`, so
focus is never dropped.

## Acceptance Coverage

- `AC-001`: CLI contract below.
- `AC-002`: Web contract below.

## Interfaces and Contracts

### CLI

- `export-cli [--input PATH] [--status active|archived] [--owner NAME] [--output PATH|-]`.
- No `--output` or `-`: standard output is exactly the CSV, standard error is
  empty, exit 0. `--output PATH`: file written, standard output empty,
  standard error `wrote <N> records to <PATH>`, exit 0.
- Missing, unreadable, non-UTF-8, or invalid JSON dump, no record list, a
  record missing a field, or an unwritable output: exit 1, standard output
  empty, standard error one line `export-cli: error: <reason>`, no traceback,
  no output file.
- Usage errors: argparse usage and error on standard error, exit 2.

### Web

- `createExportControl(document, { getFilter, exportRecords, saveFile })` in
  `packages/web/src/export-control.js` returns `{ element, button, message }`:
  `<div class="export-control">` with `<button type="button">Download CSV</button>`
  and `<p class="export-error" role="alert" tabindex="-1" hidden>`.
- Click, or Enter or Space on the focused button, calls
  `exportRecords(getFilter())` once; on success `saveFile(fileName, csv)` and
  focus stays on the button. On failure the message reads
  `Export failed: <reason>`, is shown, and receives focus; `aria-disabled` is
  removed.
- `exportRecords(filter)` in `api.js`: `POST /api/records/export` with the
  filter as query; non-2xx rejects with the body's `error` or
  `request failed with status N`; file name from `content-disposition`.

## Technical Acceptance Criteria

- `AC-001`: The stream, exit-status, and no-file rules above hold for every listed case.
- `AC-002`: Exactly one button named Download CSV, reachable with Tab and activated by click, Enter, or Space.
- `AC-002`: After a failed export the alert shows the reason and is the focused element, and the button is no longer `aria-disabled`.
- `AC-002`: A second activation while a request is in flight starts no second request.
