# Technical Design

## Context

Documentation cycle for `README.md`. The contracts below are read from the
current source; `.standards/CONTEXT.md` holds the project baseline. No
implementation change is planned.

## Decision

Document the CLI options and the configuration file as `bin/mdtoc.js` and
`src/config.js` implement them.

## Acceptance Coverage

- `AC-001`: `parseArgs` and `main` in `bin/mdtoc.js`: `--write`, `--check`,
  and `--max-depth N`; `--check` exits 1 when the table of contents is stale;
  usage, file, and configuration errors exit 2.
- `AC-002`: `loadConfig` in `src/config.js`: `.mdtocrc.json` is read from the
  current working directory; keys `maxDepth` (integer 2 to 6, default 3) and
  `bullet` (`-`, `*`, or `+`, default `-`); `--max-depth` overrides
  `maxDepth`.

## Interfaces and Contracts

- Exit statuses: 0 success, 1 stale table of contents under `--check`, 2 error.
- `--write` and `--check` cannot be combined.
