# README Configuration Section

## Goal

Readers of `README.md` can configure mdtoc without reading the source: the
guide explains the CLI options and the `.mdtocrc.json` file.

## Constraints

- Documentation-only cycle: edit `README.md` only; no changes to `bin/`,
  `src/`, `test/`, or `package.json`.
- Examples must describe existing behavior.

## Non-goals

- New options, configuration keys, or changes to defaults.

## Work

### 1. Options and configuration in the README

**Intent:** Users currently discover `--check`, `--max-depth`, and
`.mdtocrc.json` only from the source.

**Done when:**

- `AC-001`: `README.md` lists every CLI option the current `bin/mdtoc.js`
  accepts, with its effect and exit behavior.
- `AC-002`: `README.md` describes `.mdtocrc.json`: where it is read from, each
  supported key, its allowed values, and its default.

**Depends on:** None.
