# Usage Guide Accuracy

## Goal

Bring the user guide `docs/usage.md` in line with how csvsum behaves today, so
that someone following the guide gets the options and output it shows.

## Constraints

- Documentation only, under the saved request: Documenter target FILE
  `docs/usage.md`, GUIDED collaboration.
- Examples use the sample files in `docs/examples/` and describe existing
  behavior only.

## Non-goals

- Changing csvsum options, output, or error handling.
- Editing `README.md` or any file other than `docs/usage.md`.

## Work

### 1. Accurate usage guide

**Intent:** Readers rely on the guide to run csvsum without reading the source.

**Done when:**

- `AC-001`: Every option `docs/usage.md` describes exists in csvsum with the
  same name, short form, and default.
- `AC-002`: Every console example in `docs/usage.md`, run from the repository
  root, prints exactly the output shown.
- `AC-003`: `docs/usage.md` states how empty cells, non-numeric values, and an
  unknown column are handled, matching current behavior.

**Depends on:** None
