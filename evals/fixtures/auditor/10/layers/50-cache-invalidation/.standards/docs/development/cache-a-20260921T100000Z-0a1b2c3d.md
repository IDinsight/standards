### DEV-001 — Invalidate cached products on write

`Status`: `DONE` `Depends On`: `NONE` `Acceptance`: `EXPEDITED_REQUEST`

**Goal**

Stop `ProductStore` from serving a cached product object after the row has
been written, so the next read always comes from the stored row.

**Affected Area**

`src/store.js` (`ProductStore.put`, new `ProductStore.invalidate`) and
`test/store.test.js`.

**Expected Outcome**

`put` removes the sku's cache entry instead of writing the new row into the
cache; the next `get` loads the row and caches it again. `invalidate()`
empties the whole read cache.

**Self-Check**

`npm test` in the project root on the working tree with the store change;
exit 0, 9 tests passing.
