# Move the Text Helpers to app/core

## Goal

Keep shared, framework-independent helpers under `app/core/`. The text helpers
`slugify` and `truncate_words` currently sit in `app/utils/text.py`; they should
live in `app/core/text.py` without any change in what they do.

## Constraints

- The helpers' behavior, signatures, and defaults stay exactly as they are.
- The weekly digest and the digest export script keep producing the same
  output.

## Non-goals

- Changing or extending either helper.
- Moving `app/utils/dates.py` or any other module.
- Any change to API routes, services, schemas, or configuration.

## Work

### 1. Relocate the text helpers

**Intent:** Put the text helpers in the package that holds the project's shared
core code.

**Done when:**

- `AC-001`: The text helpers live in `app/core/text.py`, their callers import
  them from there, and their behavior is unchanged.

**Depends on:** None
