# Ticket CSV Export

## Goal

Support leads need to pull the ticket list into a spreadsheet for weekly
reporting. The service must be able to write tickets as a CSV file that a
spreadsheet application opens with every value in its own cell.

## Constraints

- The project uses the Python standard library only; no new dependencies.

## Non-goals

- An HTTP route, scheduled export, filtering, or column selection.
- Any change to ticket summaries.

## Work

### 1. Ticket CSV export

**Intent:** Give support leads a spreadsheet-ready file of tickets.

**Done when:**

- `AC-001`: The export writes one row per ticket with the columns id, title,
  status, and created_at.
- `AC-002`: Values that contain commas, quotes, or line breaks are quoted so
  the file opens correctly in a spreadsheet.

**Depends on:** None
