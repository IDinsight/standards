# Parser Row Helper Rename

## Goal

Give the CSV parser's private row helper a name that says what it does (it
reads data rows from an open CSV reader) and keep the parser tests in a
`tests/imports/` folder that mirrors `app/imports/`, without changing how
imports behave.

## Constraints

- Upload behavior, validation messages, the HTTP API, settings, and project
  commands stay as they are.

## Non-goals

- Changes to the public `parse_csv` function, `ImportRow`, or `ParseError`
  messages.
- Moving or changing the storage tests.

## Work

### 1. Rename the row helper

**Intent:** The helper's current name suggests it parses the whole file; the
new name matches its job of reading data rows.

**Done when:**

- `AC-001`: The parser's row helper is named `_read_rows`, and the parser
  behaves as before.

**Depends on:** None

### 2. Group the parser tests

**Intent:** Parser tests sit beside the import code they cover.

**Done when:**

- `AC-002`: The parser tests live under `tests/imports/`.

**Depends on:** None
