# Technical Design

## Decision

- Reuse `require_token` (already on `GET /imports/{import_id}`) on
  `POST /imports`.
- A new job starts `pending`; the background task sets `running`, then `done`
  or `failed` with an `error` message. The POST answers 202.
- Store the idempotency key with the SHA-256 of the file. Same key and bytes:
  return the existing job (202, no new processing). Different bytes: 409.
- Replace the fixed 10 MiB limit with a required setting `IMPORT_MAX_BYTES`
  (positive integer bytes); the API refuses to start without it.
- Split API tests into `tests/unit` and `tests/integration`, run as separate
  CI steps; add Playwright browser tests run by `pnpm test:e2e`.

## Acceptance Coverage

- `AC-001`: `require_token` on the POST handler; 401 with
  `WWW-Authenticate: Bearer` before anything is stored.
- `AC-002`: `Idempotency-Key` header; `idempotency_key` and `file_sha256`
  columns, unique on the key; 409 with `Error` on a hash mismatch.
- `AC-003`: 202 with `ImportJob` (`id`, `status`, `created_at`, `error`
  string or null); status one of `pending`, `running`, `failed`, `done`.
- `AC-004`: the page polls `pending` and `running` jobs and lists every job
  of the session with a status label, showing `error` for failed jobs.

## Interfaces and Contracts

- `POST /imports`: bearer token; multipart `file`; optional header
  `Idempotency-Key`. Responses 202 `ImportJob`, 400 empty file, 401 missing or
  unknown token, 409 key reused with a different file, 413 larger than
  `IMPORT_MAX_BYTES`; errors use `Error`.
- `GET /imports/{import_id}` returns the same extended `ImportJob`.
- `import_jobs` gains nullable `error`, `idempotency_key`, `file_sha256`
  columns, added at startup when missing.

## Technical Acceptance Criteria

- `AC-001`: no job row or file is created without a valid token.
- `AC-002`: a reused key with identical bytes returns the original id and
  schedules no processing; different bytes give 409 and no new row.
- `AC-003`: every successful POST answers 202 with a valid `ImportJob`.
- `AC-004`: pending and failed jobs appear without a reload.
