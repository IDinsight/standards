  Ask questions, report bugs, and suggest improvements through GitHub Issues.
---

Use [GitHub Issues](https://github.com/IDinsight/standards/issues) to ask about
STANDARDS, report a problem, or suggest a change. Issues are public threads: you
can comment on an existing issue or open a new one. A GitHub account is required
to post.

Before opening a new issue,
[search existing issues](https://github.com/IDinsight/standards/issues). If
someone has already raised the same topic, add your details there.

## Choose the right form

- [Ask a question](https://github.com/IDinsight/standards/issues/new?template=question.yml)
  about using STANDARDS or understanding its workflow.
- [Report a bug](https://github.com/IDinsight/standards/issues/new?template=bug_report.yml)
  when the installer, framework, or docs site behaves unexpectedly.
- [Request a feature](https://github.com/IDinsight/standards/issues/new?template=feature_request.yml)
  when a new capability would help you.
- [Suggest a documentation change](https://github.com/IDinsight/standards/issues/new?template=documentation.yml)
  when a page is unclear, missing information, or incorrect.

The forms ask for the details needed to understand and sort each request. For a
docs issue, include the page URL. For a bug, include what happened, what you
expected, and steps to reproduce it. Do not post credentials or private project
information in a public issue.
